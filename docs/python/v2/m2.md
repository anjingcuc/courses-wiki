  <h2 style="font-size:20px;">核心心智模型：四种数据结构怎么选</h2>
  <p>来自 V011 的四句话——看到数据先问「要什么」，再选结构：</p>
  <div class="pyv2-lab">
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">排队的人</span><b>list · 有序可变</b>
      <p>按位置存取、会增会删的序列。聊天记录、消息列表、待办清单。<code style="font-family:var(--pyv2-font-mono)">msgs.append(m)</code></p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag v">通讯录</span><b>dict · 键值映射</b>
      <p>用名字找内容，查找近 O(1)。API 返回的 JSON 本体、配置、计数器。<code style="font-family:var(--pyv2-font-mono)">cfg["model"]</code></p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">塑封文件</span><b>tuple · 不可变</b>
      <p>定下来就不变的组合：坐标、函数多返回值、可哈希的字典键。<code style="font-family:var(--pyv2-font-mono)">x, y = pos</code></p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">筛子</span><b>set · 唯一无序</b>
      <p>自动去重、快速判存在。URL 去重、停用词表。<code style="font-family:var(--pyv2-font-mono)">seen.add(url)</code></p>
    </div>
  </div>
  <p style="margin-top:12px;">亲手验证——这是 L7 课堂主线的简化版（浏览器内直接运行）：</p>
  <div class="py-playground" data-py-title="L7 课堂主线：API 数据 → 遍历 → 字典统计 → 排序">
    <textarea># 模拟一段大模型 API 返回的消息列表
messages = [
    {"role": "user",      "content": "你好"},
    {"role": "assistant", "content": "你好！有什么可以帮你？"},
    {"role": "user",      "content": "什么是列表推导式"},
    {"role": "assistant", "content": "一种紧凑的列表生成写法"},
    {"role": "user",      "content": "举个例子？"},
]

# 1) 遍历提取：统计每个角色说了几句话
count = {}
for m in messages:
    role = m["role"]
    count[role] = count.get(role, 0) + 1
print("各角色发言数:", count)

# 2) 推导式：抽出所有用户提问
questions = [m["content"] for m in messages if m["role"] == "user"]
print("用户提问:", questions)

# 3) 找出最长的一条消息（max + key）
longest = max(messages, key=lambda m: len(m["content"]))
print("最长消息:", longest["content"])
</textarea>

  <h2 style="font-size:20px;">函数契约：好的契约 = 好的 Prompt</h2>
  <p>L9 的核心思维。写函数前先写清楚四件事——这四件事同样是你向 AI 描述需求的四件事：</p>
  <div class="pyv2-tl">
    <div class="pyv2-tl-item" data-anim><b>名字</b><span class="meta">它做什么</span><p>count_words 而不是 func1——名字即文档，AI 也靠名字理解代码。</p></div>
    <div class="pyv2-tl-item" data-anim><b>参数</b><span class="meta">它需要什么</span><p>类型 + 含义 + 默认值，如 text: str, topk: int = 3。</p></div>
    <div class="pyv2-tl-item" data-anim><b>返回值</b><span class="meta">它给出什么</span><p>返回 dict 还是 list？空输入返回什么？异常时抛还是返 None？</p></div>
    <div class="pyv2-tl-item v" data-anim><b>示例</b><span class="meta">怎么用</span><p>docstring 里放一个 doctest 示例——既是文档，也是测试。</p></div>
  </div>
  <div class="py-playground" data-py-title="L9 练习：把课堂主线封装成函数（补全 TODO 再运行）">
