# 3.3 运行方式——命令行运行 .py 文件与 IDE 运行

## 内容梗概

本课介绍 Python 的第二种运行方式：把代码写成 `.py` 文件后用命令行运行，即 `python 文件名.py`。老师演示了在桌面新建文件、改后缀名为 `.py`、用 IDLE 打开编辑并保存（`Ctrl+S`）的全过程。重点讲解了命令行运行时的关键前提：必须先用 `cd` 命令切换到 `.py` 文件所在的目录，否则系统找不到文件会报错。此外简要说明了第三种方式——在 IDLE 等集成开发环境中用菜单的 Run（运行）快捷键直接运行。老师明确推荐第二种方式（命令行运行）。

## 知识点详解

### 第二种运行方式：命令行运行 .py 文件

- 流程：把代码写完保存成 `.py` 文件 → 在命令行中输入 `python 文件名.py` 回车运行（约 00:00）。
- 任何系统都有环境变量的概念，此方式依赖环境变量配置正确（约 00:30）。

### 新建 .py 文件（Windows 操作）

- 右键 → 新建文件 → 把后缀名改为 `.py`；系统会提示"改变文件扩展名可能导致文件不可用"，点"是"（约 00:57）。
- 注意：如果新建后看不见 `.txt` 后缀，需要在资源管理器的"查看"里勾选"文件扩展名"，否则无法正确改后缀（约 01:26）。

### 用 IDLE 编辑并保存

- 右键用 Python 自带的开发环境（IDLE）打开 `.py` 文件，输入代码（约 01:54）。
- 字符串的单引号和双引号都可以，无所谓（约 02:25）。
- 保存快捷键 `Ctrl + S`，或点菜单 Save（约 02:39）。

### 切换目录：cd 命令（关键）

- 常见错误：cmd 默认路径在 `C:\Users\用户名` 目录下，直接输入 `python 1.py` 会出错，因为文件在桌面上而不在当前目录（约 03:00）。
- 解决：用 `cd` 命令切换到文件所在目录，桌面对应的目录名是 `desktop`（桌面的英文），例如 `cd desktop`（约 03:17）。
- 切换成功后再输入 `python 1.py` 回车即可正常运行（约 03:24）。

### 第三种运行方式：IDE 内运行

- 在 IDLE 等集成开发环境中，菜单提供 Run（运行）功能及快捷键，可直接运行（约 04:53）。
- 老师明确推荐第二种方式（命令行 `python 文件名.py`），其他方式个人不太习惯（约 05:37）。

## 示例与演示

- 在桌面新建 `1.py`，用 IDLE 打开写入两行 `print(...)`（分别用双引号和单引号，`print("a")` 等示例内容），`Ctrl+S` 保存。
- 演示"天真的小白"错误：在默认目录直接运行 `python 1.py` 报错；随后 `cd desktop` 切换到桌面目录，再次运行成功。

## 重点与难点

- 运行 `.py` 文件前必须先 `cd` 切换到文件所在目录，这是新手最容易出错的地方，要多多练习 `cd` 命令。
- 资源管理器要勾选"文件扩展名"，否则改后缀名会出错。
- 单引号、双引号在 Python 字符串中等效。
- 记住保存快捷键 `Ctrl + S`。
