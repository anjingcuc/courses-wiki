    面向 AI 时代的修订版

    三个锚点 · AI 会写代码，你学什么

    能力一 读代码

    AI 生成的代码，你能看懂、能审查、能发现隐患（命名混乱、超出课程范围的语法、边界条件缺失）。这是全课程反复训练的第一项能力。

    能力二 调试

    报错是常态。读 traceback、print 定位、二分注释、最小复现——L37 专门设有「AI-free 调试日」，训练不依赖 AI 的排错能力。

    能力三 系统设计

    把模糊需求拆成模块、接口与数据流；知道何时该用 RAG、何时用 Agent、何时一个 if 就够。期末项目将全面检验这一能力。

    作业线与考核

    ① 数据处理脚本W3 发布

    处理真实 JSON/CSV：提取、转换、统计。数据结构选型是关键。

    ② API 调用项目W6 发布

    调用公开 API 获取数据并结构化处理，处理超时与错误。

    ③ 模块化重构W8 发布

    把单文件脚本重构为模块化项目，.env 管密钥。

    ④ Prompt 工程实战W9 发布

    设计结构化 Prompt 模板，鼓励大量 AI 实验。

    ⑤ RAG 迷你应用W11 发布

    小型文档问答系统：向量化、检索、生成完整链路。

    ⑥ 期末大项目W14 启动 · W16 答辩

    完整 AI 应用 + AI 协作日志 + 答辩。

    期末项目池（五选一）

    AI 知识库助手（RAG）· 智能学伴（Function Calling）· AI 创意工坊（多模态）· 智能数据分析师（NL2Code）· AI 客服机器人
