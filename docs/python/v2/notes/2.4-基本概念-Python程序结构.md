# 2.4 基本概念——Python 程序结构

## 内容梗概

本节通过一个简单的"丢骰子"程序，介绍 Python 程序的基本结构：导入库、注释、函数定义、代码块与缩进、函数调用和测试入口。重点讲解 Python 与 C 语言在代码块表示上的根本区别——C 用花括号，Python 用冒号加缩进。对有 C 语言基础的同学来说内容很简单。

## 知识点详解

### 导入库

- Python 程序开头可用 `import` 导入库，类似 C 语言 `#include` 头文件（如 stdio.h 提供 printf）（约 00:21）。
- Python 提供很多内置库和函数，例如 `random` 库提供生成随机数的功能（约 00:49）。

### 注释

- `#`（井号）后面的内容都是注释，可单独成行（约 01:01）。

### 函数定义

- 用 `def` 关键字定义函数（def 即 define 的前三个字母）（约 01:20）。
- 示例：`def row():` 定义名为 row（丢骰子）的函数；括号内是参数，行尾有一个**冒号**（约 01:38）。

### 代码块与缩进（与 C 语言的最大区别）

- 所有高级语言都有代码块概念：C 语言用**花括号** `{}` 包起来；Python 用**冒号 + 缩进**（约 01:47）。
- 规则：冒号表示开始一个新代码块，块内所有语句使用**相同的缩进**（如统一四个空格），如 `a = 1`、`b = 2` 前都空四格（约 02:11）。
- 代码块可以只有一条语句，示例中函数体内只有一句打印随机数的代码（约 02:30）。
- 顺带建议：学英语对读 Python 代码很有帮助，代码字面意思即功能（约 03:03）。

### 程序的其余组成部分

- 不定义任何函数、直接写普通语句也完全可以（约 03:22）。
- **测试入口**：相当于 C 语言 main 函数的概念。定义了函数不调用不会执行，可直接写 `row()` 调用，也可用测试入口方式调用（约 03:35）。测试入口的详细用法在讲"模块"章节时展开，现在知道概念即可。

### 程序基本结构总结

最典型结构 = 导入库 → 定义函数 → 调用（直接或通过测试入口），非常好懂（约 04:06）。

## 示例与演示

- 丢骰子示例程序：
  - `import random` 导入随机数库；
  - `#` 开头的注释行；
  - `def row():` 定义函数，函数体缩进四个空格，打印一个 1 到 7 范围内的随机数；
  - 直接调用 `row()` 或用测试入口方式调用。

## 重点与难点

- **缩进即代码块**是 Python 最核心的语法特征，冒号 + 统一缩进替代花括号，初学者（尤其有 C 基础的）最易出错。
- 缩进必须一致（示例为四个空格），混用缩进会报错。
- 函数定义后不调用不会执行；测试入口的概念先了解即可，模块章节会细讲。
- 注释用 `#`，字符串概念已在 2.2 节出现（要加引号）。
