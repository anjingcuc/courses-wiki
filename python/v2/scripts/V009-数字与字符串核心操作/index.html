    逐字稿¶

    [0:00-0:30] 开场Hook¶

    【画面】屏幕上先放一段大模型API返回的JSON响应数据，用高亮标注其中的数字、字符串、布尔值。然后打出标题：Python五种核心类型。

    【旁白】

    看，这是我们上几节课调用DeepSeek API后拿到的真实返回数据。里面这些数字——28、12、40，在Python里是什么类型？这串中文"变量是一个装数据的盒子"，又是什么类型？你可能还会注意到，JSON里有个null和true，它们到了Python里叫什么名字？今天，我们用这串AI返回的真实数据，一次性学透Python的五种核心类型。学完之后，你拿到任何一段数据，第一反应都是——先看类型。

    [0:30-1:00] 从API响应引入类型概念¶

    【画面】打开VSCode，新建一个types_demo.py文件。把模拟API响应的字典贴进去。运行前先逐行指给观众看几个值。

    【旁白】

    先说清楚一点，今天这节课不需要联网，不需要API Key。我准备了一段模拟API返回的数据，直接复制就能跑。你看，这串数据里有字符串，比如模型名"deepseek-chat"；有数字，比如token用量28、12、40；还有AI回复的文本"变量是一个装数据的盒子。"。这些数据类型各不相同，Python怎么区分它们？靠的就是类型系统。Python有五种最核心的类型，我们一个一个来看。

    [1:00-2:30] int 整数与 float 浮点数¶

    【画面】在编辑器中逐行输入代码，终端同步显示运行结果。打出字幕：① int 整数——无限精度。

    【旁白】

    第一种，int，整数类型。我们在API响应里取出total_tokens，值是40。用type()来看它的类型：

    total_tokens = api_response["usage"]["total_tokens"]
print(type(total_tokens))  # <class 'int'>

    运行，结果是<class 'int'>。这说明40是一个int。整数有什么特点？Python的整数有一个非常强大的特性——无限精度。什么意思？你写2 ** 100，就是2的一百次方，别的语言可能溢出报错，Python直接给你算出来，一长串数字，一点不丢精度。

    再来看float，浮点数，就是带小数点的数。比如我们在算API调用费用的时候：

    price_per_1k = 0.001
cost = total_tokens / 1000 * price_per_1k
print(type(cost))   # <class 'float'>
print(cost)         # 4e-05

    0.001是float，算出来的cost也是float。这里有个小知识点，4e-05就是科学计数法，等于0.00004。费用的格式化输出下节课专门讲，今天先记住——带小数点的数就是float。

    一句话区分：没有小数点的数字是int，有小数点的是float。

    [2:30-4:45] str 字符串——索引、切片与不可变性¶

    【画面】打出字幕：③ str 字符串——不可变序列。从API响应中取出AI回复文本，逐步演示索引、切片、不可变性。终端同步输出。

    【旁白】

    第三种，也是今天的大头——str，字符串。API返回的AI回复就是字符串：

    reply = api_response["choices"][0]["message"]["content"]
print(reply)         # 变量是一个装数据的盒子。
print(type(reply))   # <class 'str'>

    字符串是什么？就是用引号包起来的一段文本。单引号、双引号都行，Python不挑。

    字符串最强大的能力是——切片。什么意思？你可以按位置取出里面任意一段字符。Python里从0开始数，所以第一个字符的位置是0：

    print(reply[0])     # 变
print(reply[1])     # 量

    reply[0]取到"变"，reply[1]取到"量"。这就是索引。

    更实用的是切片，一次取一段：

    print(reply[0:5])   # 变量是一

    reply[0:5]取的是从位置0到位置4的字符，注意，左闭右开，包含0，不包含5。这个规则刚开始会觉得别扭，但用多了就习惯了，几乎所有编程语言都这样。

    再来看一个特别重要的概念——不可变性。字符串是不可变的，什么意思？你不能修改它里面的某个字符。我来演示：

    reply[0] = "我"  # TypeError: 'str' object does not support item assignment

    看，报错了。Python告诉你，字符串不支持修改单个字符。那我想改怎么办？你得创建一个新字符串：

    new_reply = "我" + reply[1:]
print(new_reply)  # 我量是一个装数据的盒子。

    reply[1:]表示从位置1开始取到最后。拼接之后得到一个全新的字符串。记住这个结论——字符串不可变，每次"修改"其实是生成了一个新字符串。

    [4:45-5:50] bool 布尔值与 NoneType¶

    【画面】打出字幕：④ bool 只有 True / False　⑤ NoneType 只有 None。在终端演示布尔运算和None的特性。

    【旁白】

    第四种，bool，布尔类型。它只有两个值——True和False。注意，Python里首字母必须大写，true全小写是JSON和JavaScript的写法，在Python里会报错。

    API返回里的finish_reason值是"stop"，这是一个字符串。但程序里我们会大量用到布尔值做判断：

    print(type(True))   # <class 'bool'>
print(type(False))  # <class 'bool'>
print(40 > 28)      # True

    40 > 28的结果就是True，它是一个bool。

    最后一种，NoneType，它只有一个值——None。None在JSON里叫null，到了Python就叫None。它表示"什么都没有""空""未定义"。比如一个API请求失败了，没有返回数据，那个变量就会被赋值为None：

    print(type(None))  # <class 'NoneType'>

    记住两点：JSON的null在Python里是None，首字母大写；None和0不一样——0是有值的，值是零；None是压根没有值。

    [5:50-7:00] 一切皆对象 + 完整闭环演示¶

    【画面】打出字幕：一切皆对象。运行完整脚本，终端一次性输出所有类型验证结果，形成闭环。

    【旁白】

    到这里五种类型都讲完了，但我还想说一个Python的核心理念——一切皆对象。什么意思？你看，type(42)返回的是<class 'int'>，type("hello")返回的是<class 'str'>。在Python的世界里，整数是对象，字符串是对象，布尔值是对象，连None都是对象。每个对象都有自己的类型，type()就是查类型的工具。

    养成一个习惯，看到任何一段数据，先问自己——它是什么类型？这个习惯能帮你避开后面无数的坑。

    来，我们把今天的完整代码跑一遍，从API响应里取值、验证类型，形成闭环：

    api_response = {
    "model": "deepseek-chat",
    "choices": [
        {
            "index": 0,
            "message": {
                "role": "assistant",
                "content": "变量是一个装数据的盒子。"
            },
            "finish_reason": "stop"
        }
    ],
    "usage": {
        "prompt_tokens": 28,
        "completion_tokens": 12,
        "total_tokens": 40
    }
}

# --- 从API响应取值并验证类型 ---

# 整数 int
total_tokens = api_response["usage"]["total_tokens"]
print(f"总token数: {total_tokens}, 类型: {type(total_tokens)}")

# 浮点数 float
price_per_1k = 0.001
cost = total_tokens / 1000 * price_per_1k
print(f"调用费用: {cost}, 类型: {type(cost)}")

# 字符串 str——索引与切片
reply = api_response["choices"][0]["message"]["content"]
print(f"AI回复: {reply}, 类型: {type(reply)}")
print(f"前5个字: {reply[0:5]}")

# 布尔值 bool
is_stop = api_response["choices"][0]["finish_reason"] == "stop"
print(f"是否正常结束: {is_stop}, 类型: {type(is_stop)}")

# NoneType
nothing = None
print(f"空值: {nothing}, 类型: {type(nothing)}")

    运行！你看，所有类型一清二楚。整数是int，费用是float，回复文本是str，判断结果是bool，空值是NoneType。这就是你的第一个"类型感知"程序。

    [7:00-8:00] 小结与引出下集¶

    【画面】屏幕上出现五种类型的速查表，每行一个：int整数 / float浮点数 / str字符串 / bool布尔 / NoneType空值。然后切换到下一集预告。

    【旁白】

    今天我们用大模型API返回的真实数据，学透了Python的五种核心类型。总结一下：int是整数，Python里无限精度；float是带小数点的数；str是字符串，可以索引和切片，但不可变；bool只有True和False；NoneType只有一个值None，表示什么都没有。

    核心习惯记住了——碰到数据，先type()看一眼类型。

    【画面】提问彩蛋：屏幕弹出字幕条，依次列出三个可以直接照抄去问 Kimi/DeepSeek 的 prompt——

    • ① 我在学 Python 字符串切片，请出 5 道练习题考我，包含中文切片和负数下标，先只出题不给答案，我做完发给你批改。
    • ② 用生活中的例子给我讲明白：Python 字符串的"不可变"到底是什么意思？为什么 reply[0] = "我" 会报 TypeError？
    • ③ 扮演 Python 面试官，围绕 int、float、str、bool、None 这五种类型连续追问我不许停，我答错就立刻纠正。

    【旁白】

    最后送你一个提问彩蛋：这三个 prompt 直接照抄去问 Kimi 或 DeepSeek。注意问法——不是把题丢给它要答案，而是让它出题考你、讲为什么、扮演面试官追你。答案背下来是 AI 的本事，被追问答得上来才是你的。

    但是，有个坑你迟早会遇到：如果API返回的token数不是数字40，而是字符串"730"，你直接拿它加1会怎样？答案是直接报错。为什么？因为字符串不能直接和数字相加。怎么解决？下节课带你讲透类型转换和f-string格式化，我们下集见。

    演示操作清单¶

    以下为录制时需要敲入的完整代码，可直接复制到 types_demo.py 运行，无需联网。

    api_response = {
    "model": "deepseek-chat",
    "choices": [
        {
            "index": 0,
            "message": {
                "role": "assistant",
                "content": "变量是一个装数据的盒子。"
            },
            "finish_reason": "stop"
        }
    ],
    "usage": {
        "prompt_tokens": 28,
        "completion_tokens": 12,
        "total_tokens": 40
    }
}

# === ① int 整数 ===
total_tokens = api_response["usage"]["total_tokens"]
print(type(total_tokens))   # <class 'int'>

# int 无限精度演示
big_number = 2 ** 100
print(big_number)           # 1267650600228229401496703205376

# === ② float 浮点数 ===
price_per_1k = 0.001
cost = total_tokens / 1000 * price_per_1k
print(type(cost))           # <class 'float'>
print(cost)                 # 4e-05

# === ③ str 字符串 ===
reply = api_response["choices"][0]["message"]["content"]
print(reply)                # 变量是一个装数据的盒子。
print(type(reply))          # <class 'str'>

# 索引
print(reply[0])             # 变
print(reply[1])             # 量

# 切片（左闭右开）
print(reply[0:5])           # 变量是一

# 不可变性——取消注释验证报错
# reply[0] = "我"  # TypeError: 'str' object does not support item assignment

# 正确做法：创建新字符串
new_reply = "我" + reply[1:]
print(new_reply)            # 我量是一个装数据的盒子。

# === ④ bool 布尔值 ===
print(type(True))           # <class 'bool'>
print(type(False))          # <class 'bool'>
print(40 > 28)              # True

# === ⑤ NoneType ===
print(type(None))           # <class 'NoneType'>

# === 完整闭环：取值 + 类型验证 ===
print("--- 类型速查 ---")
print(f"总token数: {total_tokens}, 类型: {type(total_tokens)}")
print(f"调用费用: {cost}, 类型: {type(cost)}")
print(f"AI回复: {reply}, 类型: {type(reply)}")
print(f"前5个字: {reply[0:5]}")
is_stop = api_response["choices"][0]["finish_reason"] == "stop"
print(f"是否正常结束: {is_stop}, 类型: {type(is_stop)}")
print(f"空值: {None}, 类型: {type(None)}")

    快速验证命令（终端一行）¶

    python -c "print(type(42), type(3.14), type('hello'), type(True), type(None))"
# <class 'int'> <class 'float'> <class 'str'> <class 'bool'> <class 'NoneType'>

    录制注意¶

    1. 成果前置：开场30秒内必须把API返回的JSON放到屏幕上，让观众立刻知道"今天用这串真实数据学类型"。
    2. 先敲代码再运行：每讲一种类型，先在编辑器里敲完代码，再切到终端运行。不要预先贴好所有代码再逐行念。
    3. 不可变性要动手演示：reply[0] = "我"那行先故意运行让观众看到TypeError报错，再展示正确的拼接写法。这个对比比口头说十遍都管用。
    4. 大小写强调：讲bool时口头强调True/False首字母大写，与JSON的true/false做对比，这是新手高频错误。
    5. 结尾闭环一次跑通：最后完整脚本一次性运行，让屏幕上依次输出五种类型，形成"从API取值→验证类型"的可运行闭环。
    6. 旁白字数：全文旁白约1850字，按230字/分钟约8分钟，录制时注意控制语速，关键概念处放慢。
    7. 提问彩蛋字幕：提问彩蛋段的 prompt 字幕条需在后期加上，确保观众能暂停照抄。
