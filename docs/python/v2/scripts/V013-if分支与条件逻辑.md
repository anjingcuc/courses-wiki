## 逐字稿

### [0:00-0:35] 开场 hook

**【画面】** 屏幕上放一份 API 调用日志（8 条记录），其中两条标红——一条 token 超高且失败、一条 token 正常。字幕条："500 条日志里 3 条异常，你打算用肉眼看？"

**【旁白】** 想象你有 500 条 API 调用日志，里面有几条是异常的——要么 token 消耗特别高，要么调用失败了。用肉眼看？5 分钟你眼睛就花了。但如果程序能自动判断"这条正不正常"呢？这就需要条件分支。今天教你 if/elif/else——让程序学会看情况办事。学完就能自动筛选 API 日志里的异常记录。

### [0:35-2:00] if/elif/else 基本语法

**【画面】** VS Code 中逐步敲入代码，左侧终端面板展示运行结果。

**【旁白】** 先看最简单的 if。比如判断一条 API 调用记录的 token 是不是超标：

```python
tokens = 320
if tokens > 200:
    print("高消耗，注意！")
```

`if` 后面跟一个条件，冒号结尾，下一行缩进写"条件成立时做什么"。注意——Python 用缩进表示代码块，不跟别的语言用花括号。缩进就是 4 个空格，记住。

那不超标呢？加 `else`：

```python
if tokens > 200:
    print("高消耗")
else:
    print("正常")
```

但如果我想分三档——轻量、正常、高消耗呢？用 `elif`：

```python
tokens = 45
if tokens < 50:
    print("轻量")
elif tokens <= 200:
    print("正常")
else:
    print("高消耗")
```

`elif` 就是"else if"的缩写。程序从上往下检查，命中一个就停——所以 token 等于 45 会命中第一个 `if`，打印"轻量"，后面的不再检查。

这里有个新手陷阱：如果你把 `elif` 写成多个 `if`，一条数据可能被分到好几个档里。`elif` 是"走了这个口就不走下一个"，多个 `if` 是"每个门都要查一遍"。

### [2:00-3:30] and / or / not 组合条件

**【画面】** 继续敲入组合条件代码。在 API 日志数据上演示。

**【旁白】** 现实中的条件往往不止一个。比如我要找"高消耗**并且**调用失败"的记录：

```python
tokens = 320
success = False

if tokens > 200 and not success:
    print("⚠️ 严重异常：高消耗且失败")
```

三个关键字记住——

`and`：两个条件**都成立**才算。

`or`：**任意一个**成立就算。

`not`：取反。`not success` 就是"不是成功"，也就是失败。

再看一个 `or` 的例子——判断模型是不是某个特定型号：

```python
model = "deepseek-reasoner"
if model == "deepseek-reasoner" or model == "deepseek-coder":
    print("推理/编码模型")
```

注意条件里的 `==` 是两个等号——一个等号是赋值，两个等号是判断相等。这个搞混了程序直接报错。

### [3:30-5:00] 实战：API 日志分级统计

**【画面】** 整段代码出现在屏幕上，运行后终端逐行打印统计结果。

**【旁白】** 来做一段实战——对一份真实的 API 调用日志做分级统计：

```python
call_logs = [
    {"model": "deepseek-chat", "total_tokens": 45, "success": True},
    {"model": "deepseek-chat", "total_tokens": 150, "success": True},
    {"model": "deepseek-reasoner", "total_tokens": 320, "success": False},
    {"model": "deepseek-chat", "total_tokens": 500, "success": False},
]

light = normal = heavy = 0

for log in call_logs:
    t = log["total_tokens"]
    if t < 50:
        light += 1
    elif t <= 200:
        normal += 1
    else:
        heavy += 1

print(f"轻量: {light}次, 正常: {normal}次, 高消耗: {heavy}次")
```

运行——轻量 1 次、正常 1 次、高消耗 2 次。注意这里 `for` 循环里套了 `if`——遍历每条记录，逐个判断它属于哪一档。这是实际开发中最常见的模式。

### [5:00-6:15] 实战：异常记录筛选

**【画面】** 继续在同一代码文件中追加异常筛选代码。

**【旁白】** 再来——找出"高消耗且失败"的异常记录：

```python
for log in call_logs:
    if log["total_tokens"] > 200 and not log["success"]:
        print(f"异常: {log['model']} | {log['total_tokens']} tokens | 失败")
```

运行——筛出了两条：reasoner 320 tokens 失败、chat 500 tokens 失败。就这两行代码，500 条日志也能秒筛。

再看一个变体——找出"成功**或** token 低于 50"的记录：

```python
for log in call_logs:
    if log["success"] or log["total_tokens"] < 50:
        print(f"OK: {log['model']} | {log['total_tokens']}")
```

这就是 `and` 和 `or` 的区别——`and` 是两个条件都要满足，`or` 是满足一个就行。

### [6:15-6:45] 小结 + 引出下集

**【画面】** 字幕条："if/elif/else → 分档判断 · and/or/not → 组合条件 · == 判断相等 ≠ = 赋值"

**【旁白】** 记住：if/elif/else 做分档判断，and/or/not 做组合条件，判断相等用双等号。

**【画面】** 提问彩蛋。字幕条依次列出三个可以直接照抄去问 Kimi/DeepSeek 的 prompt：

- ① 出 5 道 if/elif/else 分档练习题，场景就用"按 token 消耗给 API 调用日志分级"，难度递增，先别给答案，我写完发你批改。
- ② 给我 3 段代码，每段都把 elif 故意错写成连续的 if，让我先找出会出什么 bug，再给我讲清楚两者的区别。
- ③ 扮演面试官，围绕 and、or、not 组合条件连续追问我，比如两个条件怎么组合、取反以后什么意思，我答错就纠正我。

**【旁白】** 三个 prompt 拿走不谢。条件逻辑最怕"我以为我懂了"——看着简单，一写就错。所以别让它讲给你听，让它出题考你，卡壳的地方就是你没真懂的地方，专治眼高手低。

**【旁白】** 下集我们讲循环——当你需要对 500 条日志**每一条都做一次判断**的时候，光有 if 不够，还需要 for 循环来帮你批量处理。

### 完整演示代码

```python
# === V013 演示完整代码 ===

# --- Part 1: if/elif/else 基本语法 ---
tokens = 45
if tokens < 50:
    print("轻量")
elif tokens <= 200:
    print("正常")
else:
    print("高消耗")

# --- Part 2: and / or / not ---
tokens = 320
success = False
if tokens > 200 and not success:
    print("⚠️ 严重异常：高消耗且失败")

model = "deepseek-reasoner"
if model == "deepseek-reasoner" or model == "deepseek-coder":
    print("推理/编码模型")

# --- Part 3: 日志分级统计 ---
call_logs = [
    {"model": "deepseek-chat", "total_tokens": 45, "success": True},
    {"model": "deepseek-chat", "total_tokens": 150, "success": True},
    {"model": "deepseek-reasoner", "total_tokens": 320, "success": False},
    {"model": "deepseek-chat", "total_tokens": 500, "success": False},
]

light = normal = heavy = 0
for log in call_logs:
    t = log["total_tokens"]
    if t < 50:
        light += 1
    elif t <= 200:
        normal += 1
    else:
        heavy += 1

print(f"轻量: {light}次, 正常: {normal}次, 高消耗: {heavy}次")

# --- Part 4: 异常筛选 ---
for log in call_logs:
    if log["total_tokens"] > 200 and not log["success"]:
        print(f"异常: {log['model']} | {log['total_tokens']} tokens | 失败")

# --- Part 5: or 条件变体 ---
for log in call_logs:
    if log["success"] or log["total_tokens"] < 50:
        print(f"OK: {log['model']} | {log['total_tokens']}")
```

## 录制注意

1. **易口误**：`elif` 容易说成"else if"——Python 里写法是 `elif`，不是 `else if`。讲解时说"elif 就是 else if 的简写，但 Python 里你必须写 elif"。
2. **预埋翻车**：演示 `==` 和 `=` 的区别时，可以故意写 `if tokens = 200:` 让程序报 `SyntaxError`，然后改成 `==` 再运行通过。这个翻车点能帮观众深刻记住。
3. **字幕条重点**：and/or/not 的含义需要字幕条——"and = 两个都成立 · or = 任一个成立 · not = 取反"。
4. **时长控制点**：Part 5（or 条件变体）如果超时可砍。核心是 Part 1-4，Part 5 是加强理解用的。但如果 Part 5 砍了，结尾的引出下集要说"for 循环已经在刚才的代码里出现了"。
5. **提问彩蛋字幕**：提问彩蛋段的 prompt 字幕条需在后期加上，确保观众能暂停照抄。
