# 1.2 课程概述——结构与建议

## 内容梗概

本节介绍整门课程的教学结构和学习建议。课程将按大纲顺序从左到右逐步讲授：课程概述之后先带大家配置开发环境，然后依次学习基本数据类型、程序控制结构、Python 特有数据结构、输入输出与文件读写、标准模块，最后进入实战部分（数据分析、爬虫）。学习建议部分列了五点，老师强调最重要的是第一点：一定要自己动手写代码。

## 知识点详解

### 课程整体结构

- 课程按大纲顺序讲授，先概述、配环境，再逐步深入（约 00:24）。
- 主体内容顺序（约 01:04）：
  1. 开发环境配置；
  2. Python 基本数据类型；
  3. 程序结构（控制语句 if / else / while 等）；
  4. Python 特有的数据结构（数据类型）；
  5. 输入输出、文件读写、标准模块；
  6. 开发实例：数据分析、爬虫等。
- 关于虚拟机：本课程不用虚拟机（但下学期的课还会用到，不要急着删）（约 01:51）。

### 学习建议（五点，按重要性排序）

1. **一定要动手写代码（最重要）**（约 02:57）：后面的直播有大量操作，老师尽量放慢速度，跟着做就能学会。直播相比录播的唯一优势就是"强迫你盯着一起练"，自己看录播往往不会动手。
2. **勇于面对英文文档**（约 03:27）：很多资料没有中文版，只能看英文；初学者可先从 Python 官方文档的中英文对照版本入手，慢慢来。
3. **参考其他优秀线上课程**：网上有很多老师的视频课，讲得可能更好，本课程直播的优势只在于强制跟练。
4. **积极提问**（约 04:54）：可在微信群、直播间弹幕提问，也可以注册课程提供的课堂问答平台提问——集中式的问答平台所有同学都能看到答案，避免重复提问。
5. **学会如何提问**（约 06:22）：参考"How To Ask Questions"类资料，提问时应说明 Windows 版本、Python 版本等环境信息。

### 本节小结与预告

- 概述部分没有实质技术内容，只讲了 Python 的好处（约 06:56）。
- 下一时段讲环境配置，除操作外还会简单介绍配置背后的原理（约 07:11）。

## 重点与难点

- 最重要的建议只有一条：跟着直播动手写代码，只看不练学不会。
- 提问要提供完整环境信息（操作系统版本、Python 版本等），这是初学者常忽略的点。
- 不要因为英文文档而退缩，可先对照官方中文文档学习。
