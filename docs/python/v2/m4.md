<div class="pyv2" data-pyv2-page>
  <h2 style="font-size:20px;">L17 现场：审查一段 AI 生成的代码</h2>
  <p>这是课堂用的真实案例。左边是学生让 AI「写个函数统计词频」得到的第一版，右边是审查重构后——你能先自己找出几处问题？</p>
  <div class="pyv2-terminal">
    <div class="bar"><span class="dot r"></span><span class="dot y"></span><span class="dot g"></span><span class="title">ai_code_review.py — 左：AI 初稿 ✗ · 右：审查重构 ✓</span></div>
    <div class="body" style="min-height:0;font-size:12px;line-height:1.75;">
<span style="color:#8b98b4">问题① 密钥硬编码：</span>  api_key="sk-abc123"           <span style="color:#6ee7b7">→ os.getenv("DEEPSEEK_KEY")</span>
<span style="color:#8b98b4">问题② 命名含糊：</span>      def process(d):              <span style="color:#6ee7b7">→ def count_words(text: str) -&gt; dict</span>
<span style="color:#8b98b4">问题③ 无边界处理：</span>    text.split() 空串也照跑      <span style="color:#6ee7b7">→ if not text: return {}</span>
<span style="color:#8b98b4">问题④ 全局变量：</span>      results 写在函数外           <span style="color:#6ee7b7">→ 收进函数，返回值交付</span>
<span style="color:#8b98b4">问题⑤ 零测试：</span>        无                            <span style="color:#6ee7b7">→ assert count_words("a a b")=={"a":2,"b":1}</span>
    </div>
  </div>
  <p style="margin-top:10px;"><b>审查三步法</b>：① 密钥与敏感信息有没有进代码？② 名字能不能自解释、函数是否只做一件事？
  ③ 空输入 / 超长输入 / 非法类型会怎样？过完三问再运行验证。这套流程在 M6 项目冲刺里每天都要用。</p>
</div>

<div class="pyv2" data-pyv2-page>
  <h2 style="font-size:20px;">AI 时代为什么更需要虚拟环境</h2>
  <p>微课 V029 的核心论证——传统课程常把虚拟环境讲成可有可无的整洁习惯，在 AI 时代它已是必需：</p>
  <div class="pyv2-lab">
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">依赖冲突</span><b>项目 A 要 torch 2.1</b>
      <p>项目 B 要 torch 2.5 + transformers 4.40。装在同一个全局环境里必然有一个无法工作——虚拟环境为每个项目提供独立的依赖空间。</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag v">AI 引入的版本漂移</span><b>AI 推荐的版本各不相同</b>
      <p>每次问 AI 安装命令，它推荐的版本可能不一致。requirements.txt / Pipfile.lock 锁定精确版本，才能保证「我电脑上能跑」可复现。</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">作业硬要求</span><b>从 L16 起必查项</b>
      <p>期末项目与作业检查第一件事：有没有独立虚拟环境。pipenv install / pipenv shell 两步进入，Pipfile.lock 随项目提交。</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag v">换机 / 协作</span><b>一条命令复现</b>
      <p>队友 clone 你的项目后 pipenv install，所有依赖原样到位——协作开发的地基（配合 L5 的 Git）。</p>
    </div>
  </div>
</div>

├── Pipfile.lock     <span style="color:#8b98b4"># 精确版本锁定，协作复现</span>
├── README.md        <span style="color:#8b98b4"># 安装/运行/功能说明</span>
└── app/
    ├── <span style="color:#6ee7b7">__init__.py</span>
    ├── config.py     <span style="color:#8b98b4"># 读环境变量、常量集中管理</span>
    ├── client.py     <span style="color:#8b98b4"># 大模型 API 封装（L19 的成果放这）</span>
    ├── stats.py      <span style="color:#8b98b4"># 数据处理函数</span>
    └── main.py       <span style="color:#8b98b4"># 入口：python -m app.main</span>
