# 2.2 基本概念——IDLE 简介

## 内容梗概

本节介绍 Python 安装后自带的开发环境 IDLE，讲解两种写代码的方式：交互模式（`>>>` 提示符下输一句执行一句）和编辑器模式（新建文件写多行代码后保存运行）。最后让大家把课程概述里的 turtle 表白代码贴进来运行，以此验证环境是否安装成功——运行成功即环境配置完成，暂不要求理解代码。

## 知识点详解

### IDLE 是什么

- 安装成功后，开始菜单出现 Python 3.8 文件夹，其中有 IDLE（约 00:05）。
- IDLE 是首字母缩写：**Integrated Development and Learning Environment（集成开发与学习环境）**（约 00:33）。
- 一般语言的开发环境叫 IDE（集成开发环境），如 C 语言的 Visual Studio、Java 的 Eclipse；Python 自带的 IDLE 多了一个 L（Learning）（约 00:46）。

### 交互模式

- 打开 IDLE 默认进入**交互模式**窗口（专业术语），标志是 `>>>` 提示符（约 02:03）。
- 用法：在 `>>>` 后输入一句 Python 代码回车，立即执行并显示结果。例如输入 `1 + 2` 回车输出 `3`；用内置函数 `print(...)` 可在屏幕打印一句话（约 02:43）。
- 优点：特别适合学习，想试一个小功能随时输入验证（约 03:47）。
- 缺点：写多行程序（如 turtle 画图代码）时要逐行输入，还要考虑缩进，非常繁琐——**除学习验证外一般不用交互模式写程序**（约 04:01）。

### 编辑器模式（正式写代码的方式）

- 菜单 **File → New File** 新建文件，弹出类似记事本的编辑器窗口，可写多行符合 Python 语法的代码（约 04:48）。
- 注意：Python 中的字符串要加引号，如 `a = "编辑器"`，然后 `print(a)` 输出（约 05:37）。
- 保存：按 **Ctrl+S** 或点 Save，选择位置（如桌面）命名保存（约 05:55）。
- 运行：菜单 **Run → Run Module** 或直接按 **F5**，运行结果显示在交互窗口中（约 06:04）。

### 用 turtle 代码验证环境

- 从课程概述页面复制 turtle 表白代码，在 IDLE 新文件中粘贴（Ctrl+V 或右键 Paste）（约 07:21）。
- **务必先保存再运行**：标题栏的未保存标记（*号）消失才说明保存好了（约 07:47）。
- 运行后开始画图即说明环境正常；可自行修改代码中的文字（如把名字改成自己的）（约 08:19）。
- **目的说明**：此练习只为测试环境安装是否成功，不要求现在理解 turtle 代码，后面章节才会讲（约 08:53）。
- turtle 现在是 **Python 内置模块**，无需安装第三方库即可使用（约 09:32）。

## 示例与演示

- 交互模式演示：`1 + 2` 得 3；`print("...")` 打印文字。
- 编辑器演示：新建文件 → 定义变量 `a = "编辑器"` → `print(a)` → Ctrl+S 保存到桌面 → F5 运行出结果。
- 完整流程演示：复制 turtle 表白代码 → 粘贴进新文件 → 保存 → 运行 → 修改文字后再次运行。

## 重点与难点

- 分清两种模式：**交互模式**（`>>>`，即输即得，适合验证小功能）与**编辑器模式**（新建文件、保存、F5 运行，正式开发方式）。
- 运行前必须保存文件，留意标题栏的未保存标记。
- 本节的 turtle 程序只是环境测试工具，跑通即可，不必纠结代码含义。
- 字符串必须加引号，这是初学者常犯的语法错误。
