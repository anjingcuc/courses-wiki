# 3.1 运行方式——交互模式

## 内容梗概

本课介绍 Python 的第一种运行方式——交互模式（逐行输入代码）。交互模式有两种进入方法：直接双击安装好的 `python.exe`，或在命令行（cmd/PowerShell）中输入 `python` 回车进入。老师详细演示了如何打开 cmd 命令行窗口（开始菜单右键→运行→输入 `cmd`，或快捷键 `Windows+R` 后输入 `cmd`）。进入交互模式的标志是提示符 `>>>`（三个大于号）。此外，IDLE 这个集成开发环境也可以进入交互模式。老师强调命令行是本课程后续经常使用的基础工具，务必记住进入方式。

## 知识点详解

### 交互模式的进入方式

- 方式一：双击安装好的 `python.exe`，直接弹出交互模式窗口（约 00:08）。
- 方式二：在命令行（cmd 或 PowerShell）中输入 `python` 回车进入交互模式（约 01:23）。
- 交互模式的标志：提示符为 `>>>`（三个大于号），表示当前处于 Python 解释器提供的交互状态，可以逐行输入代码（约 00:23）。

### 打开命令行窗口（cmd）

- 方法一：开始菜单右键 → 运行 → 在弹出框中输入 `cmd` 回车（约 01:37）。
- 方法二：快捷键 `Windows + R`（R 即 Run 的首字母）弹出运行窗口，输入 `cmd` 回车（约 02:11）。
- Windows 10 下还有 PowerShell 命令行，本课只讲 cmd，不展开（约 01:48）。

### IDLE 的交互模式

- IDLE 这个集成开发环境也可以进入交互模式，同样可行（约 03:25）。

## 示例与演示

- 在交互模式中输入 `print("hello world")`（口播示例），回车立即打印 `hello world`，体现交互模式逐行执行的特点（约 00:41）。
- 现场演示双击 `python.exe` 进入交互模式，以及在 cmd 中输入 `python` 进入交互模式。

## 重点与难点

- `>>>` 三个大于号是判断是否处于交互模式的标志。
- 命令行是本课程后续经常使用的工具，进入方式（`Windows+R` → `cmd`）必须记住。
- 老师特别提示：不要因为交互模式简单就忽略命令行的学习，后面会经常用。
