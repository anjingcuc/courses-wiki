  <h2 style="font-size:20px;">亲手搓一个「迷你语义检索」</h2>
  <p>还没申请 embedding 接口？词集合重叠度（Jaccard）就是最朴素的「语义」近似。L23 课堂正是从这里出发，
  再升级到真向量检索。浏览器里直接跑：</p>
  <div class="py-playground" data-py-title="L23 前置实验：手搓迷你检索（RAG 的检索环节）">
    <textarea>import json

# 迷你知识库：课程 FAQ 切块
chunks = [
    {"id": 1, "text": "成绩构成 平时作业50 期末项目50 无上机考试"},
    {"id": 2, "text": "允许AI协作 纸面小测 指行讲思路 答辩三问"},
    {"id": 3, "text": "期末项目池 知识库助手 智能学伴 创意工坊 数据分析师 客服机器人"},
    {"id": 4, "text": "RAG 检索增强 向量化 语义检索 切分"},
]

def to_set(text: str) -> set:
    return set(text.split())

def jaccard(a: set, b: set) -> float:
    if not a or not b:
        return 0.0
    return len(a & b) / len(a | b)

def retrieve(query: str, k: int = 2) -> list:
    q = to_set(query)
    scored = [(jaccard(q, to_set(c["text"])), c) for c in chunks]
    scored.sort(key=lambda t: t[0], reverse=True)   # 按相似度降序
    return [c for s, c in scored[:k] if s > 0]

# 试试不同的问题，观察命中的块
for q in ["期末成绩怎么算", "RAG 是什么", "能组队吗"]:
    hits = retrieve(q, k=2)
    print(q, "→", [c["id"] for c in hits] or "无命中")
</textarea>
  </div>
  <p style="margin-top:10px;">追问：Jaccard 检索「能组队吗」为什么会失败？（词面没有重叠）——这正是 embedding 要解决的问题：
  <b>把「意思」变成空间中的距离</b>。详见 <a href="scripts/V042-RAG原理向量与语义检索.md">V042</a>。</p>
</div>

  <h2 style="font-size:20px;">L20 精要：结构化 Prompt 五件套</h2>
  <div class="pyv2-tl">
    <div class="pyv2-tl-item" data-anim><b>角色</b><span class="meta">你是谁</span><p>「你是课程助教」——对应 API 的 system 消息，定人设、定边界。</p></div>

    <div class="pyv2-tl-item v" data-anim><b>输出格式</b><span class="meta">给谁看</span><p>要被程序解析就明确 JSON Schema（L21 的 JSON Mode 是它的工程化版本）。</p></div>
