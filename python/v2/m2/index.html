    M2 语言核心

    MODULE 2 · L6–L11 语言核心
    6 课时13 集微课V009–V021

    模块设计原则

    AI 时代的语法课不是「人肉文档」：每课建立思维模型，不逐个方法展开；方法查询交给 AI 和文档； 核心代码手写、细节代码 AI 辅助。贯穿示例全部来自大模型 API 场景——学习语法的同时就在接触 AI 开发。 课堂主线一览：JSON 取值学类型（L6）→ API 数据学结构（L7）→ 条件筛选学控制流（L8）→ 封装复用学函数（L9）→ 存档排错学 IO 异常（L10）→ AI 对话管理器学类（L11）。

    L6数据类型与变量作业①发布
    整数（无限精度、进制）、浮点数、字符串（不可变性、索引切片、f-string）、布尔与 None；type() 与类型转换；「一切皆对象」。

    四种结构一句话定位；核心操作（增删改查、遍历）；选型思维；推导式入门。主线：API 返回的 JSON 列表 → 遍历提取 → 字典统计 → 排序输出。

    核心心智模型：四种数据结构怎么选

    来自 V011 的四句话——看到数据先问「要什么」，再选结构：

    排队的人list · 有序可变

    按位置存取、会增会删的序列。聊天记录、消息列表、待办清单。msgs.append(m)

    通讯录dict · 键值映射

    用名字找内容，查找近 O(1)。API 返回的 JSON 本体、配置、计数器。cfg["model"]

    塑封文件tuple · 不可变

    定下来就不变的组合：坐标、函数多返回值、可哈希的字典键。x, y = pos

    筛子set · 唯一无序

    自动去重、快速判存在。URL 去重、停用词表。seen.add(url)

    函数契约：好的契约 = 好的 Prompt

    L9 的核心思维。写函数前先写清楚四件事——这四件事同样是你向 AI 描述需求的四件事：

    名字它做什么

    count_words 而不是 func1——名字即文档，AI 也靠名字理解代码。

    参数它需要什么

    类型 + 含义 + 默认值，如 text: str, topk: int = 3。

    返回值它给出什么

    返回 dict 还是 list？空输入返回什么？异常时抛还是返 None？

    示例怎么用

    docstring 里放一个 doctest 示例——既是文档，也是测试。
