### [0:00-0:35] 开场 hook：AI 能写代码了，你的竞争力在哪？

**【画面】** 屏幕上播放一段新闻截图拼接——"AI 自动通过某公司编程面试""AI 编程工具用户突破千万"——两条标题交替闪过。画面中央弹出大字："程序员还有价值吗？"停顿一秒后，大字碎裂，切换成另一句话："有——但不是你想的那种。"字幕条："AI 时代程序员成长路线"。

**【旁白】** 先看两条新闻。第一条，AI 自动写代码通过了某家公司的编程面试。第二条，AI 编程工具用户已经突破千万。你看完可能会慌——程序员还有价值吗？答案是：有。但价值的来源变了。这集不讲代码，讲的是——这门课结束之后，你该怎么继续走。

### [0:35-2:15] 四维能力模型：你的竞争力由什么组成

**【画面】** PPT 展示一张四维雷达图，四个顶点分别是"基础能力""AI 协作""工程化""领域知识"。每个维度标注 1-5 分。然后用动画在雷达图上画出"课程结束时学生的典型分布"——基础能力 3-4 分、AI 协作 4 分、工程化 2-3 分、领域知识 1-2 分。图形形成一个明显的"偏科"形状。

**【旁白】** 先建一个模型。AI 时代程序员的能力，可以拆成四个维度。

第一个，基础能力——编程语法、数据结构、系统思维。这是你们 48 节课在练的硬功夫。会写 for 循环不稀奇，但能判断什么时候用循环、什么时候用字典、怎么把一段逻辑封装成函数——这些是地基。

第二个，AI 协作能力——Prompt 设计、vibe coding、代码审查。这是这门课的特色增量。大部分教程还在教你怎么手写每一行代码，而你们已经学会了用 AI 生成代码、审查代码、增量验证。这节课教的能力，很多在职程序员都还没掌握。

第三个，工程化能力——测试、部署、版本控制、协作、文档。期末项目你们练了一轮，但说实话，离"长期维护一个真实项目"还差得远。这是要靠时间和项目量堆出来的。

第四个，领域知识——你选择的行业。金融、医疗、教育、电商——每个领域都有自己的一套业务逻辑。这是最特殊的维度，因为它不是靠学编程能补的，得去实际行业里泡。

现在看你自己的雷达图。课程结束时，典型分布是这样的：基础和 AI 协作偏强，工程化中等，领域知识最弱。这很正常。但有一个直觉很重要——**如果你前三维都不错，补领域知识的性价比最高**。因为一个懂金融的 Python 开发者，比一个只会 Python 的开发者值钱得多。领域知识是最难被 AI 替代的。

### [2:15-4:15] 四个方向：你现在可以走哪些路

**【画面】** PPT 展示一张四列路线图，每列代表一个方向，分三层：顶部"已有基础"、中部"进阶技能"、底部"推荐资源"。四列分别是"后端工程师""数据分析师""AI 应用开发者""产品工程师"。讲到哪个方向就高亮哪一列。

**【旁白】** 有了能力模型，来看具体方向。四个方向不是互斥的——你可能同时是"AI 应用开发者"加"有金融领域知识"。交叉方向往往最有价值。

方向一，后端工程师。你们已有的基础是 FastAPI、API 设计、异常处理。进阶需要补的是：深入数据库，SQL 和 ORM；Docker 容器化，上一集 V057 刚讲过概念；还有 Linux 运维基础、消息队列这些。后端是所有互联网应用的地基，岗位需求最稳定。

方向二，数据分析师。你们学过 Pandas、Matplotlib、数据获取。进阶要补的是：SQL 进阶、可视化工具比如 Tableau 或 Power BI、统计学基础、机器学习入门比如 scikit-learn。Kaggle 竞赛是最好的练手平台。

方向三，AI 应用开发者。这是和这门课最相关的方向。你们已经会了 LLM API 调用、Prompt 工程、RAG、Agent、多模态。进阶要补的是：LangChain 或 LlamaIndex 框架、专业向量数据库、Docker 部署、模型微调概念。目前市场上"Python 加 AI"的岗位需求是爆发式增长的。

方向四，产品工程师。前端加后端加 AI 加产品思维——最接近 vibe coding 创业者的角色。进阶要补前端框架 React 或 Vue、产品需求分析、用户体验设计。如果你未来想自己做产品、做独立开发者，这个方向最适合。

记住一句话：**方向感是走出来的，不是想出来的**。选一个"最不排斥"的方向开始，做的过程中会越来越清楚自己喜欢什么。不需要现在就定死。

### [4:15-5:50] 持续学习：不是什么都学，是快速判断该学什么

**【画面】** PPT 展示一个三层信息漏斗图。第一层（宽口）："泛信息源"——GitHub Trending、HuggingFace Trending、Hacker News、掘金。第二层（中口）："深度信息源"——3-5 个高质量博客或公众号、1-2 个技术播客。第三层（窄口）："实践验证"——用 AI 问三个问题，全过关才花 1 小时做 demo。

**【旁白】** 技术发展太快，每周都有新模型、新框架、新概念。怎么跟上？关键不是什么都学——你的时间有限。核心策略是：建立"信息分级过滤"机制。

第一级，泛信息源——知道"有什么新东西"。GitHub Trending 每周看一次，HuggingFace Trending 看 AI 模型动态，Hacker News 或掘金看技术聚合。这层只花你 15 分钟，目的是保持信息宽度，不用深入。

第二级，深度信息源——理解"这个新东西好不好"。关注 3 到 5 个高质量技术博客或公众号，听 1 到 2 个技术播客。这层帮你建立判断力，知道哪些趋势是真机会、哪些是泡沫。

第三级最关键——实践验证，判断"适不适合我"。当你对某个新技术感兴趣，先别急着花几天去学，用 AI 帮你做第一轮筛选。问它三个问题。

**【画面】** 屏幕切换到 Kimi Code 终端演示，输入一段 prompt："帮我评估 CrewAI 这个框架：1. 它解决什么问题？和 LangChain 有什么区别？2. 学习成本高不高？我已会用 Python 调 LLM API 做 Agent。3. GitHub 活跃度如何？最近一次更新是什么时候？"展示 AI 回复的要点摘要。

第一，它解决什么问题？比现有方案好在哪？第二，学习成本多高？文档质量怎么样？第三，社区活跃度怎么样？有没有被放弃的风险？三个问题都过关，再花一小时做一个最小 demo。如果哪个环节卡住了——跳过。这就是 AI 时代的持续学习：不是什么都学，而是用 AI 帮你快速过滤噪音，只投入真正有价值的方向。

### [5:50-7:00] 开源贡献：你最好的简历不是简历

**【画面】** PPT 展示一个 GitHub 个人主页截图（示意），高亮三处：绿色贡献格子图、Pull Request 列表、"good first issue"标签的 issue。旁边配文字："开源贡献 = 最有说服力的简历"。

**【旁白】** 最后聊一个很多人想做但不知道怎么开始的事——开源贡献。

很多人觉得开源很高门槛，得是大牛才能参与。不是的。从哪开始？第一步，找一个你用过的开源项目，比如 FastAPI。读它的源码和 Issues，看看别人在讨论什么。第二步，找标了 `good first issue` 的问题——这是专门给新手准备的，项目维护者已经标记好了"这个不难，适合新人上手"。第三步，别一上来就想改核心代码。修文档错别字、改进注释、补充示例代码——这些都是贡献。

而且你们有一个别人没有的优势——用 AI 加速理解。看不懂代码？让 AI 给你逐行解释。改了代码不确定对不对？让 AI 帮你 review。AI 是你的结对编程伙伴。

为什么强调这个？因为你的 GitHub 主页——那些绿格子、那些 PR 记录——是最好的简历。面试官看到你有真实的开源贡献，比看到你刷了 500 道算法题更有说服力。因为它证明了你能读别人的代码、能和团队协作、能解决真实问题。

### [7:00-7:45] 小结：三种永不过时的能力

**【画面】** 字幕条逐条出现，配三张小图标："理解问题""设计方案""用工具实现"。前两个图标标为"核心竞争力"，第三个标注"AI 改变了这步的效率"。最后浮现总结句："技术会变，这三种能力不会。"

**【旁白】** 回到开头那个问题——AI 能写代码了，你的竞争力在哪？

记住三件事。第一，代码能力是入场券，不是护城河。AI 协作加领域理解加系统设计，这个组合才是不可替代的。第二，用四维能力模型定期自检——基础、AI 协作、工程化、领域知识——找到你的短板。第三，持续学习不是什么都学，是用 AI 快速判断该学什么。

有一句话送给你们：**技术会变，但三种能力永不过时——理解问题、设计方案、用工具实现。AI 改变的是第三步的效率，前两步是你的核心竞争力。** 这 48 节课，你们花最多时间练的恰恰就是这三件事。

### [7:45-8:05] 提问彩蛋

**【画面】** 字幕条逐条列出三个 prompt，每条停留数秒供观众暂停照抄：

1. "按四维能力模型（基础能力、AI 协作、工程化、领域知识），我给自己打 4/4/2/1 分。请分析这个组合的短板，并给我一个 3 个月提升计划，每周能投入约 5 小时。"

**【旁白】** 彩蛋时间——这三条 prompt 直接照抄去问 AI。还是那句话：把 AI 当教练，别当代写。让它诊断你的短板、追着你问，比让它替你做事值钱得多。

## 录制注意

1. **开场新闻截图要有真实感**：开场用的两条"AI 编程"新闻标题，建议从真实媒体报道中选取并截图（可模糊来源 logo），制造紧迫感。不要用纯文字 PPT 模拟——真实截图的冲击力远高于文字。但注意不编造虚假新闻，选择真实存在的报道即可。
2. **雷达图用动画逐步绘制**：四维能力雷达图不要一次性全部展示——先画坐标轴和四个维度标签，再动画绘制"课程结束时典型分布"的形状，最后用虚线叠加"目标组合"的形状。让观众看到从"当前"到"目标"的差距，比静态展示更有教学效果。
3. **AI 评估演示要真实运行**：展示物4 的 Kimi Code 评估 CrewAI 演示，必须真实运行并展示实际输出，不要用后期文字合成。如果录制时 AI 输出与本集预设内容有出入，以实际输出为准，旁白据此调整即可——这反而更能体现"真实使用 AI"的过程。
4. **语速和情绪控制**：本集旁白约 1850 字，按 230 字/分钟控制在 8 分钟以内。整体基调是"冷静但鼓舞人心"——不要灌鸡汤，也不要焦虑营销。用数据和事实说话，让学生自己得出"我有竞争力"的结论。结尾引出 V059 时语气可以稍放松，带有"快结束了"的仪式感。
5. **提问彩蛋字幕条后期添加**：提问彩蛋段的 prompt 字幕条需在后期加上，确保观众能暂停照抄。
