→

需要拿到的三样东西： ① Base URL（服务器在哪，校内是 openai.cuc.edu.cn）② API Key（控制台创建，永不过期） ③ 模型 ID（比如 deepseek-cuc）——三者齐了，工具就变成 Agent 了。

包管理器：都是同一个架构

你的终端
pip install requests
→
索引服务器
这本书的目录（轻、快）
→
文件服务器
真正的包（大、可 CDN 加速）
  • 操作系统层：winget（Windows）/ brew（Mac）/ apt · yum（Linux）
  • 编程语言层：pip（Python）/ npm · pnpm（Node.js）/ cargo（Rust）
  • 它们背后的逻辑完全一样：先查索引 → 找文件 → 下载 → 检查依赖 → 递归 → 本地安装

理解了架构，换语言换系统都不再陌生——这是「学思想而非背命令」的第一个例子。

Python 环境：三种选择

官方安装包Python 3.14.x + pip
  • python.org 下载，自带 pip
  • 装包要编译时很痛苦（需要本地编译环境）
Anaconda → Miniconda科学计算全家桶 / 精简版
  • Anaconda 900M+ 塞 500 个科学计算包（太重）
  • Miniconda ≈ 90M：Python + conda + 少量默认包——推荐用它上课
UV新一代包管理器 用 Rust 写的、更快；虚拟环境放在项目文件夹里（conda 默认堆在 C 盘用户目录下）。 推荐 Miniconda + UV 都装上。

虚拟环境：到底是什么

  • 虚拟环境 = 项目专属的独立 Python 空间（envs 文件夹）
  • 激活环境 = 运行一堆设置环境变量的逻辑（看 activate.ps1 就明白）
  • UV 的虚拟环境在项目文件夹里；conda 默认堆在 C 盘
# 激活后，项目里的脚本这么跑：
uv run main.py          # UV 帮你激活虚拟环境再执行
# 或手动：
.venv\Scripts\activate  # Windows
python main.py

虚拟环境里很干净——只有 Python + pip + 你自己装的库。这正是「我对这个环境有把握」的原因。

动手：让 AI 帮你初始化环境

在桌面上建一个项目文件夹（建议英文名，比如 python-course），然后在 AI 工具里：

"我现在这个项目想用 Python 做，用 UV 作为包管理器，
 帮我在本地初始化所需环境。"
  • 它会帮你建 UV 环境、初始化 Git 仓库、建好示例脚本和 README——你要懂它在干什么
  • 给 AI 任务时越具体越好：说要 Python 几、要不要装默认包（上节课的三要素）

文件夹别用中文名——中文路径在很多工具里会有莫名其妙的坑。

读报错：本课的基本功

# 常见错误：文件找不到
C:\Users\me> python hello.py
python: can't open file 'hello.py': [Errno 2] No such file or directory

# 读报错从最后一行往前读——原因：你不在 hello.py 所在的目录
C:\Users\me> cd Desktop\python-course
C:\Users\me\Desktop\python-course> python hello.py
Hello, world!
  • 三个最常见报错：文件找不到（目录不对）、命令未找到（PATH 问题）、缩进错误
  • 排错第一步：先看自己在哪个目录（cd / dir）
  • 遇到报错别慌——读最后一行，它通常直接告诉你原因
