    V005 AI 编程工具全家桶安装¶

    视频信息¶

    目标时长 8 min
    对应课次 L3 命令行运行与 AI 工具链

    一句话定位 在命令行里跟 AI 聊天、在编辑器里让 AI 补全——把你的 AI 编程伙伴全装好

    逐字稿¶

    [0:00–0:35] 开场 Hook：成果前置¶

    【画面】 快速快进演示（5 秒）：终端里输入一行自然语言指令，AI 在编辑器中生成完整代码，代码跑通，终端输出结果。画面定格，弹出字幕：这是怎么做到的？

    【旁白】 刚才你看到了什么？我在命令行里说了一句话，AI 就帮我写了代码，然后直接跑通了。这不是科幻，这就是你接下来几个月每天都在用的开发方式。今天这一集，把你的 AI 编程工具全部装好——命令行的、编辑器里的，一个都不少。

    [0:35–2:30] Kimi Code CLI：命令行里的 AI 对话¶

    【画面】 录屏：终端中执行安装命令。安装完成后，输入 kimi-code 启动。进入对话模式后，输入 prompt，AI 返回一段 Python 代码。

    【旁白】 第一个工具：Kimi Code CLI。CLI 就是命令行界面，你直接在终端里跟 AI 对话。安装方式很简单，终端里运行安装命令——具体命令看你的系统，到 Kimi Code 官网复制就行。

    装好了，终端输入 kimi-code 回车。看，它进入了对话模式。我输入一个问题试试："帮我写一个 Python 程序，打印当前时间。"回车，AI 返回了一段代码。你看，它用了 datetime 模块，获取当前时间然后打印出来。这就是 vibe coding 的雏形——你描述需求，AI 写代码。

    Kimi Code CLI 适合什么场景？快速问答、生成小脚本、解释一段代码。不用打开编辑器，终端里一句话搞定，特别高效。

    [2:30–4:30] Trae：编辑器里的 AI 副驾驶¶

    【画面】 录屏：打开 Trae 编辑器。快速过界面：编辑区、终端面板、AI 对话面板。在编辑器里用自然语言描述"写一个函数，接收用户名字，打印欢迎信息"。AI 在编辑区内生成代码。阅读代码 → 修改欢迎语内容 → 运行验证。

    【旁白】 第二个工具：Trae。它是一个内置了 AI 能力的编辑器，界面跟 VSCode 很像。打开看一下——左边文件树，中间编辑区，下面终端，右边是 AI 对话面板。

    我现在在编辑区里直接用自然语言描述需求："写一个函数，接收用户名字，打印欢迎信息。"AI 就在编辑器里生成了代码——一个 greet 函数，参数是 name，打印一句欢迎语。生成的代码你要先读一遍：函数名、参数、逻辑，看懂了再运行。我还可以改一下，比如把欢迎语改成"欢迎来到 Python 课堂"。改完运行，看输出对不对。

    Trae 适合什么场景？边写代码边辅助。你在编辑器里写，AI 随时帮你补全、修改、生成新函数。它就像坐在你旁边的副驾驶。

    [4:30–5:30] opencode：轻量级终端 AI 助手¶

    【画面】 录屏：终端中安装 opencode，运行 opencode，快速展示对话界面。字幕条标注它与 Kimi Code CLI 的区别：更轻量、多模型切换。

    【旁白】 第三个工具叫 opencode，也是一个终端里的 AI 编程助手。安装方式和 Kimi Code 类似。它的特点是轻量、启动快，而且可以切换不同的模型。你可以把它当成一个备选方案——工具不怕多，关键是在不同场景下你有得选。

    这三个工具不用全装，选你顺手的就行。如果你只装一个，我建议先装 Kimi Code CLI——后面课程的命令行操作会经常用到它。

    [5:30–7:00] 核心知识点：编辑器是驾驶舱，AI 是副驾驶¶

    【画面】 左右分屏对比：左边终端里用 Kimi Code CLI 问答，右边 Trae 编辑器里写代码+AI 补全。中间弹出字幕：编辑器 = 驾驶舱 AI = 副驾驶 你是机长。

    【旁白】 现在你手上有两类 AI 工具了。命令行里的 Kimi Code CLI 和 opencode，适合快速问答、生成小片段；编辑器里的 Trae，适合边写边辅助。它们不矛盾，是互补的。

    但不管你用哪个工具，有一个关系你要记住：编辑器是你的驾驶舱，AI 是你的副驾驶，而你是机长。AI 帮你干粗活——写代码、补全、解释，但做什么、做不做、做对了没有，这些决策权在你手里。AI 生成的东西不一定对，你必须运行验证。这句话后面课程我会反复说。

    [7:00–7:55] 练习布置、小结与提问彩蛋¶

    【画面】 练习清单字幕条：① 安装 Kimi Code CLI ② 问 AI 一个 Python 问题 ③ 把有用的代码存到 .py 文件 ④ 命令行运行验证。

    【旁白】 课后练习：装好 Kimi Code CLI，用它问一个 Python 问题——比如"Python 里单引号和双引号有什么区别"。然后把 AI 回答中你觉得有用的知识点，加到自己的代码注释里，用命令行跑起来。

    【画面】 字幕条逐条弹出三个可直接照抄的 prompt（每条停留供暂停截图）： ① 我在 Kimi Code CLI、Trae、opencode 之间做选择。请扮演工具选型顾问，先连续问我 5 个关于使用场景的问题，再给出推荐。 ② 对比讲解：命令行 AI 工具和编辑器里的 AI 助手各有什么优劣势？用表格对比，再各举一个最合适的使用场景。 ③ 生成一个 15 行左右的 Python 函数，故意留一个逻辑问题，让我练习审查 AI 写的代码，我找出问题后你再点评。

    【旁白】 彩蛋来了。工具装好后，别只让 AI 替你写——下次它生成代码，先别急着运行，把代码发回去问一句"这段有没有问题"。一来一回，读代码的本事就练出来了。这三条 prompt 照抄去用。

    【画面】 弹出下集标题卡：V006 大模型 API 是什么。

    【旁白】 下一集我们往深走一步：这些 AI 工具背后，大模型 API 到底是什么？我们下集见。

    演示操作清单¶

    Kimi Code CLI 安装与使用¶

    # 安装（以官方文档为准，命令可能随版本更新）
pip install kimi-code        # 或按官网指引安装
# Mac 用户：pip3 install kimi-code

# 启动对话模式
kimi-code

# 演示用 prompt
# 帮我写一个 Python 程序，打印当前时间。

    AI 预期返回的代码（演示用）：

    import datetime
now = datetime.datetime.now()
print("当前时间:", now.strftime("%Y-%m-%d %H:%M:%S"))

    Trae AI 补全演示¶

    1. 打开 Trae 编辑器
2. 新建文件 greet.py
3. 在编辑区/AI面板输入：
   "写一个函数，接收用户名字，打印欢迎信息"
4. AI 生成代码 → 阅读 → 修改欢迎语 → 运行验证

    AI 预期返回的代码（演示用）：

    # greet.py — 欢迎函数
def greet(name):
    print(f"欢迎来到 Python 课堂，{name}！")

greet("同学")

    python greet.py    # 预期输出：欢迎来到 Python 课堂，同学！

    # 安装（以官方文档为准）
# 参考官网安装指引

# 启动
opencode

    注意：以上安装命令可能随版本更新而变化，录制前请到各工具官网确认最新安装方式。Kimi Code CLI 为课程主力工具，优先确保安装成功。

    录制注意¶

    1. 安装命令要录前核实：AI 编程工具更新极快（调研报告指出半衰期约 3-6 个月），录制前务必到 Kimi Code / Trae / opencode 官网核实最新的安装命令和启动方式。字幕条中标注"命令以官网为准"。
    2. 工具装不上要有预案：Kimi Code CLI 可能因网络/权限装不上。准备备用方案：如果装不上，用浏览器打开 Kimi 网页版做同样的对话演示，旁白说明"工具形态不同，本质一样"。
    3. AI 生成代码必须运行验证：Trae 段落中 AI 生成的 greet 函数，务必现场运行并展示输出。旁白强调"AI 生成的不一定对，必须运行验证"——这是全课程反复出现的原则。
    4. 三个工具不要等量齐观：Kimi Code CLI 是课程主力（后续课程频繁使用），Trae 次之，opencode 只是提一嘴作为备选。旁白明确建议"先装 Kimi Code CLI"。时长分配已体现这个优先级。
    5. 提问彩蛋：提问彩蛋段的 prompt 字幕条需在后期加上，确保观众能暂停照抄。
