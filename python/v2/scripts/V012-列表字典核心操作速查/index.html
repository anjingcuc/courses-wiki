    逐字稿¶

    [0:00-0:30] 开场 hook¶

    【画面】 屏幕上快速闪过一段代码——十几行 for 循环做统计的代码，然后"唰"地被一行推导式替换。字幕条："10 行代码 → 1 行代码"。

    【旁白】 上节课你知道了列表管顺序、字典管映射。但具体怎么增删改查？怎么遍历？怎么一行代码提取你要的数据？今天我给你一张速查表——不是把所有方法背一遍，而是只学最高频的那几个，加一个推导式技巧，搞定日常 80% 的操作。

    [0:30-2:00] 列表核心操作¶

    【画面】 VS Code 中打开 Python 文件，左侧终端面板可见。逐步敲入列表操作代码并运行。

    【旁白】 先看列表。我们用 API 消息列表做演示——这比什么 [1, 2, 3] 真实多了。

    增——append 在末尾加一条：

    messages = []
messages.append({"role": "system", "content": "你是助手"})
messages.append({"role": "user", "content": "你好"})

    查——用下标，从 0 开始：

    print(messages[0])    # 第一条
print(messages[-1])   # 最后一条，-1 是倒数第一个

    改——直接赋值：

    messages[1] = {"role": "user", "content": "请重新回答"}

    删——pop() 按位置删，remove() 按值删：

    messages.pop(0)   # 删掉第一条

    就这四个——增、查、改、删。其他方法用到的时候问 AI 就行，不用背。

    [2:00-3:30] 字典核心操作¶

    【画面】 新建一个代码段，继续在同一文件中演示字典操作。

    【旁白】 再看字典。字典的操作和列表很像，区别是——列表按位置（0、1、2），字典按 key。

    增/改——直接赋值，key 不存在就是新增，存在就是修改：

    stats = {}
stats["total"] = 5          # 新增
stats["total"] = 6          # 修改
stats["model"] = "deepseek-chat"

    查——两种方式，区别很大：

    print(stats["total"])           # 直接取，key 不存在会报错
print(stats.get("tokens", 0))   # get 取，不存在返回默认值 0，不报错

    重点记住 .get() ——在 API 开发里你经常不确定某个字段在不在，用 get 比直接取安全得多。

    遍历——三个方法，最常用的是 .items()：

    for key, value in stats.items():
    print(f"{key}: {value}")

    一次拿到 key 和 value，写循环的时候这个最实用。

    [3:30-5:15] 列表推导式¶

    【画面】 屏幕分屏：左边是传统 for 循环写法（5 行），右边是推导式写法（1 行），用箭头连接。

    【旁白】 下面是今天的重头戏——推导式。先看一个痛点：我要从消息列表里提取所有 user 的消息内容。

    传统写法，5 行：

    user_messages = []
for msg in messages:
    if msg["role"] == "user":
        user_messages.append(msg["content"])

    推导式，1 行：

    user_messages = [msg["content"] for msg in messages if msg["role"] == "user"]

    读法是：左边的表达式，for 遍历列表，if 筛选条件。

    其实就是把 for 循环倒着写——先写你要的东西（msg["content"]），再写从哪遍历（for msg in messages），最后写筛选条件（if msg["role"] == "user"）。

    再来一个例子——提取所有 token 超过 100 的调用记录：

    call_logs = [
    {"model": "deepseek-chat", "total_tokens": 45},
    {"model": "deepseek-chat", "total_tokens": 150},
    {"model": "deepseek-reasoner", "total_tokens": 320},
]
heavy_calls = [log for log in call_logs if log["total_tokens"] > 100]
print(heavy_calls)

    运行——筛出了 150 和 320 两条。你看，分支加循环的事，推导式一行就干了。

    [5:15-6:15] 字典推导式（快速过）¶

    【画面】 继续敲代码，终端面板展示输出。

    【旁白】 列表推导式会了，字典推导式也类似——把方括号换成花括号，左边写 key: value：

    # 从调用日志创建 model→token 的映射
token_map = {log["model"]: log["total_tokens"] for log in call_logs}
print(token_map)
# {'deepseek-chat': 150, 'deepseek-reasoner': 320}

    注意——如果有重复的 key，后面的会覆盖前面的。这里是 deepseek-chat 出现两次，最终值是最后一条的 150。

    [6:15-6:45] 可运行闭环：日志统计¶

    【画面】 运行一段完整的统计代码，终端逐行打印结果。

    【旁白】 最后一段完整闭环——对 API 日志做统计，列表和字典配合使用：

    call_logs = [
    {"model": "deepseek-chat", "total_tokens": 45},
    {"model": "deepseek-reasoner", "total_tokens": 300},
    {"model": "deepseek-chat", "total_tokens": 120},
]

# 字典统计每个模型的总 token
totals = {}
for log in call_logs:
    model = log["model"]
    totals[model] = totals.get(model, 0) + log["total_tokens"]

# 遍历输出
for model, total in totals.items():
    print(f"{model}: {total} tokens")

    运行——deepseek-chat 总共 165，reasoner 总共 300。这就是字典做计数统计的标准套路：get 取默认值 0，加完赋回去。

    [6:45-7:00] 小结 + 引出下集¶

    【画面】 字幕条："列表：append/下标/pop · 字典：get/items · 推导式：[表达式 for x in 列表 if 条件]"

    【旁白】 记住这几个就够日常用了：列表 append 加、下标查、pop 删；字典 get 取、items 遍历；推导式一行搞定筛选提取。

    【画面】 提问彩蛋。字幕条依次列出三个可以直接照抄去问 Kimi/DeepSeek 的 prompt：

    • ① 请出 5 道改写题：每题给一段 for 循环筛选列表的代码，让我改写成列表推导式，我写一句发你批改一句。
    • ② 用一张表对比字典的 stats["key"] 直接取和 stats.get("key", 0)：分别在什么情况下会报错？各举一个 API 开发里的例子。
    • ③ 扮演代码评审：我发你一段用 for 循环统计字典的代码，请指出 3 个可以写得更简洁的地方并说明理由，先别直接给改好的代码。

    【旁白】 老规矩，三个 prompt 照抄去用。重点是第三条——让 AI 当评审挑你代码的毛病，而不是让它直接替你写。它挑出来的每个毛病，都是你下次少踩的一个坑。

    【旁白】 下集我们学 if 分支和条件逻辑——当你需要让程序"根据情况做不同处理"的时候，就该它上场了。

    演示操作清单¶

    完整演示代码¶

    # === V012 演示完整代码 ===

# --- Part 1: 列表核心操作 ---
messages = []
messages.append({"role": "system", "content": "你是助手"})
messages.append({"role": "user", "content": "你好"})
messages.append({"role": "assistant", "content": "你好！"})

print("第一条:", messages[0])
print("最后一条:", messages[-1])

messages[1] = {"role": "user", "content": "请重新回答"}
messages.pop(0)  # 删掉第一条

print("操作后:", messages)

# --- Part 2: 字典核心操作 ---
stats = {}
stats["total"] = 5
stats["total"] = 6
stats["model"] = "deepseek-chat"

print(stats["total"])
print(stats.get("tokens", 0))  # 不存在返回 0

for key, value in stats.items():
    print(f"{key}: {value}")

# --- Part 3: 列表推导式 ---
all_messages = [
    {"role": "system", "content": "你是助手"},
    {"role": "user", "content": "你好"},
    {"role": "assistant", "content": "你好！"},
    {"role": "user", "content": "天气怎样"},
]

# 传统写法
user_messages_old = []
for msg in all_messages:
    if msg["role"] == "user":
        user_messages_old.append(msg["content"])

# 推导式写法
user_messages = [msg["content"] for msg in all_messages if msg["role"] == "user"]
print("用户消息:", user_messages)

# token 筛选
call_logs = [
    {"model": "deepseek-chat", "total_tokens": 45},
    {"model": "deepseek-chat", "total_tokens": 150},
    {"model": "deepseek-reasoner", "total_tokens": 320},
]
heavy_calls = [log for log in call_logs if log["total_tokens"] > 100]
print("高消耗记录:", heavy_calls)

# --- Part 4: 字典推导式 ---
token_map = {log["model"]: log["total_tokens"] for log in call_logs}
print("模型→token映射:", token_map)

# --- Part 5: 闭环——日志统计 ---
totals = {}
for log in call_logs:
    model = log["model"]
    totals[model] = totals.get(model, 0) + log["total_tokens"]

for model, total in totals.items():
    print(f"{model}: {total} tokens")

    录制注意¶

    1. 易口误：stats.get("tokens", 0) 的第二个参数是默认值——容易说成"默认值是 0 如果不存在"这种绕口的表达。提前练顺：get 方法，第一个参数是 key，第二个是找不到时返回的默认值。
    2. 推导式讲解节奏：推导式是本集核心。讲解时一定要指着代码从左到右念——"先写你要的结果，再写 for 从哪来，最后写 if 要什么条件"。念两遍，观众才能记住顺序。
    3. 字幕条重点：列表和字典的操作对照表值得出一个字幕条——"列表：下标[0] / 字典：key名['role']"，帮观众记住取值方式的区别。
    4. 时长控制点：字典推导式（Part 4）如果时间紧可以砍掉，只保留列表推导式。字典推导式标记为"选学"，不影响主线。
    5. 提问彩蛋字幕：提问彩蛋段的 prompt 字幕条需在后期加上，确保观众能暂停照抄。
