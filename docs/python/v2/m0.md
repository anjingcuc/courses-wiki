<div class="pyv2" data-pyv2-page>
  <h2 style="font-size:20px;">核心观念：AI 时代的三种不可替代能力</h2>
  <p>来自微课 <a href="../scripts/V001-AI时代为什么学编程/">V001</a> 的定调——AI 把「写代码」这件事的成本降到了接近零，但有三件事它给不了你：</p>
  <div class="pyv2-lab">
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">能力 ①</span><b>读代码</b>
      <p>AI 生成的代码你得看得懂，才能判断对不对、安不安全。比如 AI 把 API 密钥直接写进代码——不懂代码的人根本看不见这个隐患。</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">能力 ②</span><b>调试</b>
      <p>AI 不会一次性写对。报错了、行为不对了，能定位问题、能修——这是纯靠 AI 给不了的能力，也是 M6「AI-free 调试日」要锤炼的。</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">能力 ③</span><b>系统设计</b>
      <p>AI 是执行者；做什么、分几个模块、数据怎么流，是人定的。AI 是辅助驾驶，你是机长——关键时刻你得能接管方向盘。</p>
    </div>
  </div>

  <h3 style="margin:18px 0 8px;">vibe coding 工作流（五步循环）</h3>
  <p>课堂上那个 10 分钟做出的 AI 聊天网页，过程拆开就是：<b>描述需求 → AI 生成 → 人审查 → 运行验证 → 微调迭代</b>。
  AI 干了最耗时的「写」环节，但每一步的决策权都在人手里。这门课教的，就是握住决策权的本事。</p>
</div>
