    V002 用大模型学编程的正确姿势¶

    视频信息¶

    项目 内容
    编号 V002
    标题 用大模型学编程的正确姿势
    目标时长 8 min
    对应课次 L2 AI辅助学习法与环境初配
    前置微课 V001 AI时代为什么学编程
    一句话定位 同一个 AI，为什么有人用完说"太菜了"，有人说"改变了我的人生"？差距在提问

    逐字稿¶

    [0:00–0:35] 开场 Hook：同一个 AI，天壤之别¶

    【画面】 左右分屏。左边标题"坏提问"，右边标题"好提问"。两个对话框同时弹出——左边输入"帮我写一个 Python 程序"，右边输入一段结构完整的需求描述。

    【旁白】 同样一个大模型，有人用完说"就这？太菜了"，有人用完说"这东西改变了我的人生"。差距在哪？不在 AI，在你怎么问。今天我现场做个对比实验：同一个 AI，同一个需求，两次不同的问法，你看输出质量差多少。

    [0:35–2:30] 坏提问 vs 好提问：现场对比演示¶

    【画面】 录屏：打开 Kimi 网页版。先输入坏 prompt 并展示 AI 的回复（泛泛的猜数字游戏代码）。清空对话。再输入好 prompt，展示 AI 的回复（结构清晰、带注释的成绩排序代码）。

    【旁白】 我们先来看坏提问。我问 AI："帮我写一个 Python 程序。"就这么一句话。AI 会给我什么？一个猜数字游戏，或者一个 Hello World。因为我的需求太笼统了，AI 只能给你一个最泛泛的示例。这不叫 AI 不行，这叫你没说清楚你要什么。

    现在我换个问法。我说："我是 Python 零基础学生。帮我写一个程序：读取一个 JSON 文件，里面是学生成绩列表，格式是 name 和 score 两个字段，按分数从高到低排序后打印出来。请加上中文注释，并解释每行的作用。"你看看 AI 这次给的：结构清晰，有注释，有解释，拿过来几乎就能直接用。同一个 AI，输出质量天差地别。

    [2:30–5:00] 核心知识点：提问三维框架¶

    【画面】 PPT 动画或字幕条，三个维度依次弹出：① 上下文 ② 具体目标 ③ 约束条件。每个维度配一行好/坏对比示例。

    【旁白】 差距在哪？我们对比一下两次提问，把规律总结出来。一个好问题要包含三个维度。

    第一，上下文。坏提问什么都不说背景；好提问说清楚"我是 Python 零基础学生"，这样 AI 就知道用入门级别来回答，不会给你整一堆你看不懂的高级语法。上下文还包括你的项目背景、技术栈、运行环境——交代得越多，AI 越不容易跑偏。

    第二，具体目标。坏提问说"帮我写个程序"——做什么的程序？完全没说。好提问说"读取 JSON 文件，按分数排序后打印"——目标非常明确。目标越具体，AI 越不需要猜，给你的东西就越精准。

    第三，约束条件。"加中文注释"是一个约束，"用 Python 标准库"是一个约束，"代码不超过 30 行"也是一个约束。约束条件相当于给 AI 画了跑道，让它在该跑的范围内发挥。

    记一个公式：好问题 = 上下文 + 具体目标 + 约束条件。这三个维度齐了，AI 给你的回答质量会翻好几倍。

    [5:00–6:30] 用 AI 辅助排错：提问能力在真实场景中的价值¶

    【画面】 录屏：模拟一个安装报错场景——命令行显示 python 不是内部或外部命令。然后展示如何把完整错误信息发给 AI，AI 给出修复方案。

    【旁白】 提问能力不只是用来写代码。你学编程的过程中，最大的时间消耗不是写代码，而是装环境、改报错。比如你装完 Python，命令行输入 python，系统告诉你"不是内部或外部命令"。很多人这时候就懵了。但如果你会提问，把这个错误信息原封不动发给 AI，再补上你的操作系统和安装路径，AI 一下就能告诉你：你安装的时候忘了勾选 Add to PATH，需要怎么怎么修。所以从第一天起，养成一个习惯：遇到问题，先把错误信息完整地发给 AI，看它怎么说。但前提是——你得能把问题描述清楚。

    [6:30–7:30] 48 课全景地图¶

    【画面】 展示 48 课课程地图，7 个模块一览。三个里程碑高亮标注：L4 第一次调通 API L23 RAG 实战 L31 项目启动。

    【旁白】 最后给你看看我们这门课的全景。48 节课，7 个模块：导论、环境工具、语言核心、数据获取、工程化、AI 应用开发、综合项目。有几个关键里程碑你记住：第 4 课，你就会亲手调通大模型 API——从那以后你就能说"我可以用代码跟 AI 对话了"；第 23 课，你会搭一个能读文档回答问题的 AI 系统；第 31 课开始，你正式进入期末大项目阶段。从第 1 课到第 4 课只有 3 节课的准备时间，所以每一节都要跟上。

    [7:30–8:25] 小结、提问彩蛋与下集预告¶

    【画面】 公式再次出现：好问题 = 上下文 + 具体目标 + 约束条件。

    【旁白】 总结一下：用好 AI 的关键不是 AI 有多强，而是你会不会提问。记住三维框架：上下文、具体目标、约束条件。

    【画面】 字幕条逐条弹出三个可直接照抄的 prompt（每条停留供暂停截图）： ① 给我一个"烂提问"（比如"帮我写个程序"），让我用"上下文+具体目标+约束条件"框架把它改写成好提问，改完你打分并说明理由。 ② 这是我的报错信息：（粘贴你的报错）。请不要直接给答案，用连续提问的方式引导我自己找到原因。 ③ 扮演一位严格的编程老师，就"如何向 AI 提出好问题"连续向我追问 5 个问题，一个比一个深入。

    【旁白】 彩蛋时间。把刚学的三维框架用在"让 AI 教你"上：让它出题、让它追问、让它只给提示不给答案。这三条 prompt 直接照抄去试。你会发现，好问题能要到的不只是答案，还有练习和反馈。

    【画面】 弹出下集标题卡：V003 Python 与 VSCode 安装速通。

    【旁白】 下一集，我们进入实操环节——7 分钟带你装好 Python 和 VSCode，跨过编程学习的第一道坎。我们下集见。

    演示操作清单¶

    坏 Prompt（对比演示用）¶

    帮我写一个Python程序

    好 Prompt（对比演示用）¶

    我是Python零基础学生。帮我写一个程序：读取一个JSON文件，里面是学生成绩列表，
格式如 [{"name": "张三", "score": 85}, ...]，按分数从高到低排序后打印出来。
请加上中文注释，并解释每行的作用。

    排错演示 Prompt¶

    我在 Windows 11 上安装了 Python 3.12，但在命令行输入 python 显示
"不是内部或外部命令"。我的 Python 安装路径是
C:\Users\我的用户名\AppData\Local\Programs\Python\Python312。
怎么解决？

    以上 prompt 均在 Kimi 网页版（kimi.com）中操作演示，也可用其他大模型替代，效果类似。

    录制注意¶

    1. 对比演示要真实：两个 prompt 必须在同一次录制中连续展示，先坏后好，让学生直观感受到差距。建议使用同一个对话窗口的"新对话"功能，保证对比公平。
    2. 三维框架是本片灵魂：上下文、具体目标、约束条件——这三个词必须在字幕条中出现，并在旁白中反复强调。这是学生要带走的核心知识点。
    3. 课程地图节奏要快：6:30 的全景图段不要逐个模块展开讲，快速过一遍即可，重点是三个里程碑（L4/L23/L31）。
    4. 时长控制：对比演示段（0:35–2:30）弹性最大——如果 AI 回答很长，可以只展示关键部分，关键是让学生看到"好坏输出的质变"。
    5. 提问彩蛋：提问彩蛋段的 prompt 字幕条需在后期加上，确保观众能暂停照抄。
