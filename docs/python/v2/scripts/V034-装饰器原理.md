**【旁白】** 看个魔术。这是一个普通函数，运行，正常输出。现在我不动函数体一行代码，只在它头顶加一行 `@timer`——再运行，函数自己多了一项能力：每次执行完自动报告耗时。函数还是那个函数，但它被"增强"了。这个 `@` 开头的写法叫装饰器，你以后会在 AI 生成的代码里、在 FastAPI 这样的框架里反复见到它。今天八分钟，讲清楚它到底是什么。

### [0:30-2:00] 预备知识：函数是一等公民

**【画面】** PPT 展示三行代码：`f = say_hi`（函数赋值给变量）、`call_twice(say_hi)`（函数当参数传）、`return greeter`（函数当返回值）。每行配一个标签："能赋值 · 能传参 · 能返回"。字幕："在 Python 里，函数和数字、字符串一样，是个值"。

**【旁白】** 讲装饰器之前，先补一个认知，这是理解一切的基础——**在 Python 里，函数是一等公民**。

啥叫一等公民？就是函数跟数字、字符串、列表一样，是一个"值"，能被传来传去。三个证据。

第一，函数能赋值给变量。`def say_hi()` 定义完之后，写 `f = say_hi`——注意没有括号，有括号是调用它，没括号是把这个函数本身递给 f。然后 `f()` 一样能执行。

第二，函数能当参数传给别的函数。我写一个 `call_twice(func)`，里面 `func()` 调两次，然后把 `say_hi` 传进去——它就打印两遍。

第三，函数能当返回值。一个函数可以 return 另一个函数——这一点最关键，装饰器靠的就是它。

记住一句话：**def 定义函数时，你其实在创建一个值，这个值可以被赋值、被传递、被返回。** 这是今天唯一需要你新建的认知。

### [2:00-4:10] 手写装饰器：接收函数，返回函数

**【画面】** VS Code 中从零写出 `timer` 装饰器，逐行高亮：`def timer(func)` → `def wrapper()` → `return wrapper`。右侧动画：原函数被"包"进 wrapper 里，像给手机贴膜。然后展示不用 @ 的手动用法：`greet = timer(greet)`。

**【旁白】** 有了"函数是值"这个认知，装饰器就水到渠成了。**装饰器就是一个函数——它接收一个函数，返回一个新函数。**

来，从零写一个。目标：给任意函数加计时功能。

```python
import time

def timer(func):            # 接收一个函数
    def wrapper():          # 在里面定义一个新函数
        start = time.time()
        func()              # 调用原来的函数
        end = time.time()
        print(f"⏱️ 耗时 {end - start:.3f} 秒")
    return wrapper          # 把新函数返回出去
```

三层结构看清楚：最外层 `timer` 接收原函数 func；中间 `wrapper` 是包了一层的新函数——在原函数前后各加了一段代码；最后 `return wrapper`，把这个增强版交出去。

怎么用？先不用任何新语法，纯手动：

```python
def greet():
    print("你好！")

greet = timer(greet)   # 把 greet 换成包装后的新函数
greet()                # 打印"你好！" + 报告耗时
```

`greet = timer(greet)` 这一行是灵魂——把原函数交给 timer，timer 还回来一个增强版，名字还叫 greet。之后每次调用 greet，走的都是 wrapper 那条路：先记时间，再干活，再报时。原函数体一行没改，功能却多了。就像给手机贴膜——手机没换，但多了层保护。

### [4:10-5:40] @ 语法糖 + *args/**kwargs 通用化

**【画面】** 左边展示手动写法 `greet = timer(greet)`，右边展示 `@timer` 写在函数头顶，中间一个等号连接，标注"完全等价"。然后展示带参数的 `greet("小明")` 报 TypeError，给 wrapper 加上 `*args, **kwargs` 后修复。

**【旁白】** 每次手写 `greet = timer(greet)` 有点啰嗦，Python 给了一个专门的简写——`@`：

```python
@timer
def greet():
    print("你好！")
```

`@timer` 写在函数定义头顶，意思跟 `greet = timer(greet)` **一模一样**，没有任何区别。它就是语法糖——同样的意思，更甜的写法。你以后看到函数头顶有个 `@xxx`，脑子里直接翻译成"这个函数被 xxx 包装了一层"。

还有个细节。现在的 wrapper 是 `def wrapper()`，不收参数——如果被装饰的函数有参数，比如 `greet("小明")`，就报错了。怎么办？用你们学过的 `*args, **kwargs`——V016 讲过的"什么参数都能收"的写法：

```python
def timer(func):
    def wrapper(*args, **kwargs):       # 什么参数都收
        start = time.time()
        result = func(*args, **kwargs)  # 原样传给原函数
        end = time.time()
        print(f"⏱️ {func.__name__} 耗时 {end - start:.3f} 秒")
        return result                   # 返回值也别弄丢
    return wrapper
```

三个要点：wrapper 用 `*args, **kwargs` 收参数，原样转交给 func；func 的返回值存下来 return 出去，不然调用方拿不到结果。这两个坑是新手写装饰器最常踩的。另外提一句，AI 生成的装饰器里你常看到一行 `@functools.wraps(func)`，作用是保留原函数的名字和文档——知道它是干什么的就行，本课程不要求会用。

### [5:40-6:50] 看懂框架代码：@app.get 在做什么

**【画面】** 展示一段 FastAPI 代码，高亮 `@app.get("/")` 和 `@app.post("/chat")` 两行。标注："带参数的装饰器 = 把函数登记给框架"。字幕："看到 @ 不发懵——函数被包了一层 / 被登记了"。

**【旁白】** 现在回头看框架代码。L27 我们要用 FastAPI 写后端，代码长这样：

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    return {"msg": "hello"}

@app.post("/chat")
def chat():
    return {"reply": "你好"}
```

`@app.get("/")` 比 `@timer` 多了个括号——它叫"带参数的装饰器"。你不需要会写它，只需要看懂它在干什么：**它把下面这个函数登记给了框架**——"以后有人访问斜杠这个网址，就调用 root 函数；有人往 /chat 发 POST 请求，就调用 chat 函数"。函数本身的活还是你写，但"什么时候被调用"这件事，交给框架管了。

这就是今天最重要的收获——不要求你手写复杂装饰器，只要求你以后看到 `@xxx` 顶在函数头上，心里立刻有画面：**这个函数被包了一层，或者被登记给了某个系统。** 看懂 AI 生成的代码、看懂框架示例，全靠这一眼。

```python
# demo_first_class.py —— 函数是一等公民的三个证据

def say_hi():

def make_greeter():
    def greeter():
        print("我是被返回的函数")

g = make_greeter()

```

### 演示2：手动装饰（不用 @，证明 @ 只是语法糖）（demo_manual.py）

```python
# demo_manual.py —— 不用 @ 的手动装饰
import time


def timer(func):
    """装饰器：接收一个函数，返回带计时功能的新函数"""
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"⏱️ {func.__name__} 耗时 {end - start:.3f} 秒")
        return result
    return wrapper


def hello():
    time.sleep(0.5)
    return "hello"

# 手动装饰：等价于在 def hello 头顶写 @timer
hello = timer(hello)

print(hello())
```

### 演示3：@timer 完整闭环（demo_timer.py）

```python
# demo_timer.py —— 装饰器闭环：给任意函数加计时
import time


def timer(func):
    """装饰器：接收一个函数，返回带计时功能的新函数"""
    def wrapper(*args, **kwargs):       # 什么参数都收
        start = time.time()
        result = func(*args, **kwargs)  # 原样调用原函数
        end = time.time()
        print(f"⏱️ {func.__name__} 耗时 {end - start:.3f} 秒")
        return result                   # 原函数的返回值别弄丢
    return wrapper


@timer
def greet(name):
    """打招呼，故意 sleep 1 秒模拟慢操作"""
    time.sleep(1)
    return f"你好，{name}！"


@timer
def slow_add(n):
    """从 1 加到 n"""
    total = 0
    for i in range(1, n + 1):
        total += i
    return total


if __name__ == "__main__":
    print(greet("小明"))        # 先打印耗时，再打印问候语
    print(slow_add(10000000))   # 从 1 加到一千万
```

预期输出：

```
⏱️ greet 耗时 1.003 秒
你好，小明！
⏱️ slow_add 耗时 0.537 秒
50000005000000
```
