    [0:00-0:35] 开场 hook：你站在什么山上？¶

    【画面】 屏幕中央出现一张完整的技术版图，自下而上分四层：基础设施层、模型层、框架与工具层、应用层。应用层高亮标注"你的期末项目在这里"。画面缩小，旁边浮现一行字："48 节课，你学了这么多——但你知道它们各自站在哪一层吗？"

    【旁白】 刚做完期末项目，你用 Python 调了 DeepSeek 的 API，写了 RAG 知识库，搭了 FastAPI 后端，还做了前端聊天页面。这些技术名词你都很熟了。但退一步想——这些技术在整个 AI 生态里分别站在哪一层？你学的东西是"造发动机"还是"造汽车"？今天花八分钟，带你把这张全景图看清。

    [0:35-2:15] AI 应用的四层技术栈¶

    【画面】 PPT 展示四层架构图，从下到上逐层揭示。底层"基础设施层"：GPU/TPU/云计算/数据中心，标注"不需要你管"。第二层"模型层"：GPT-4/Claude/DeepSeek/Qwen/Ollama，标注"你调 API 用"。第三层"框架与工具层"：FastAPI/LangChain/向量数据库，标注"课程教了"。顶层"应用层"：AI 知识库/智能学伴/你的期末项目，标注"你在这里"。每层用不同颜色区分。

    【旁白】 先建立一张整体地图。AI 应用技术栈分四层，从底到顶。

    最底下是基础设施层——GPU 集群、云计算、数据中心。这是大公司烧钱的地方，你不用管。

    往上一层是模型层——GPT-4、Claude、DeepSeek、还有各种开源大模型。这一层提供"智能"，你在课程里从第四节课开始就在调它们的 API。

    再往上是框架与工具层——FastAPI 帮你搭 Web 后端，向量数据库帮你存 Embedding，LangChain 帮你封装 AI 工作流。这一层是"中间件"，连接模型和你的应用。

    最顶层就是应用层——AI 知识库助手、智能学伴、AI 创意工坊。你做的期末项目就在这一层。

    记住一个关键认知：课程 48 节课，从第一天到结业，从来没有让你训练模型。你做的是站在巨人肩膀上——用现成的模型，搭出解决真实问题的应用。模型是发动机，你造的是汽车。

    [2:15-3:30] 模型层：闭源 API 与开源模型¶

    【画面】 PPT 左右分栏对比。左栏"闭源 API"：DeepSeek、GPT-4、Claude、Kimi，标注"云端调用、按量付费、能力最强"。右栏"开源模型"：Llama、Qwen、DeepSeek 开源版，标注"可本地部署、免费、可微调"。中间箭头标注"2024 起开源模型能力快速逼近闭源"。

    【旁白】 聚焦模型层。现在分两大阵营。

    左边是闭源 API——你调用 DeepSeek、GPT-4，模型跑在别人的服务器上，你按 token 付费。优点是能力强、不用管硬件，缺点是数据要传出去、长期使用有成本。

    右边是开源模型——Llama、通义千问 Qwen、DeepSeek 也开源了自己的模型权重。你可以把模型下载到本地，自己跑。优点是免费、数据不出门，缺点是吃硬件、需要自己部署。

    2024 年开始，开源模型的能力在快速逼近闭源。这意味着什么？意味着你有更多选择——对数据隐私敏感的场景可以用本地模型，追求最强效果的场景可以用云端 API。两条路都通。

    [3:30-5:00] 三大趋势：开源崛起、多模态融合、Agent 自主化¶

    【画面】 PPT 展示三列，每列一个趋势。第一列标题"开源模型崛起"，图标：开源 logo + 向上箭头。第二列"多模态融合"，图标：文本+图片+语音+视频图标汇聚。第三列"Agent 自主化"，图标：齿轮循环。每列下方一句话解释对开发者的影响。

    【旁白】 看看当前 AI 领域的三大趋势。

    第一个趋势——开源模型崛起。刚才说了，DeepSeek 开源了权重，Qwen 系列持续迭代。这意味着技术不再被几家大公司垄断，普通人也能下载模型本地跑。对开发者来说，依赖第三方 API 的风险在降低。

    第二个趋势——多模态融合。以前大模型只处理文本，现在能看图、能听语音、能生成图片和视频。你在课程 L24 学过 Vision API 和 TTS——那就是多模态。未来应用不再是纯文字聊天，而是看图说话、听音办事。

    第三个趋势——Agent 自主化。你在课程 L25-L26 学过 AI Agent——AI 不只是回答问题，而是能自己拆任务、调工具、多步完成目标。2025 年这个方向是最热的赛道，从简单工具调用走向真正自主决策。

    这三个趋势有个共同点：你学的底层能力——调 API、做 RAG、写 Agent——不会过时。变的是模型更强、模态更多、Agent 更聪明。但"理解架构 + 选对工具 + 快速上手"这个核心能力，一直值钱。

    [5:00-6:15] 三大平台：HuggingFace / Ollama / ModelScope¶

    【画面】 浏览器分三个标签页。标签1打开 huggingface.co/models 页面，展示模型排行榜，按下载量排序，高亮 Qwen2.5 模型卡片。标签2打开 ollama.com 展示模型列表页面。标签3打开 modelscope.cn 魔搭社区首页。每个页面旁边浮一行中文标注。

    【旁白】 了解趋势之后，你需要知道去哪找模型和工具。三大平台。

    第一个，HuggingFace——它是 AI 模型界的 GitHub。你需要找模型、找数据集、看别人做的 Demo，这里是第一站。按下载量排序就能看到当前最火的开源模型。点开任何一个模型卡片，能看到参数量、许可证、使用示例。

    第二个，Ollama——它让你一键在本地运行大模型。安装后一行命令 ollama run qwen2.5 就能和本地模型对话。不需要 API Key，不需要网络，离线也能跑。在数据隐私敏感的场景，比如医疗和金融，这个能力非常关键。

    第三个，ModelScope 魔搭社区——国内的版本，内容和使用方式和 HuggingFace 类似，访问速度快很多。如果你觉得 HuggingFace 打开慢，就用魔搭。

    这三个平台你不需要全注册，知道有它们存在就行。需要的时候，知道去哪找。

    [6:15-7:00] 实操演示：Ollama 本地跑模型¶

    【画面】 终端演示。先运行 ollama run qwen2.5:0.5b，展示交互对话——输入"你好，请用一句话介绍自己"，模型返回回复。然后切到 VS Code，展示一段 Python 代码：base_url 改成 http://localhost:11434/v1，其他代码和课程里调 DeepSeek 一模一样。运行后展示输出。

    【旁白】 来看个实际的。终端里 ollama run qwen2.5:0.5b，等它下载完，就能直接对话。这是一个 5 亿参数的小模型，速度快但能力有限——如果你想效果更好，换 7B 以上的模型，当然也更吃内存。

    重点看这个：切到 VS Code，这段代码你一定很眼熟——就是课程 L4 学的 openai SDK 调用。唯一区别是 base_url 从 DeepSeek 换成了 localhost:11434。其他一行都不用改。这就是 OpenAI 兼容接口的威力——学一套代码，云端和本地的模型都能用。你之前写的所有调用代码，一行不改就能切换到本地模型。

    [7:00-7:45] 你的位置：应用层开发者¶

    【画面】 回到开场的四层架构图，镜头拉近应用层。应用层高亮，旁边浮现金句："模型是发动机，你的应用是汽车。发动机再好，没有方向盘、刹车、座椅——也只是一堆轰鸣的金属。"然后展示一行时间线："理解架构 → 选对工具 → 快速上手"。

    【旁白】 最后回到核心问题——你在整个版图里站在哪？

    你站在应用层。你的价值不在于训练模型，而在于"理解业务需求、设计架构、实现体验"。模型是发动机，你的应用是汽车。发动机再好，没有方向盘、刹车、座椅，也只是一堆轰鸣的金属。

    技术版图会持续变化——明年可能 LangChain 就不流行了，新的框架又冒出来。但你的核心能力不变：理解架构，选对工具，快速上手。遇到新名词，用 AI 帮你三句话搞清楚，判断它值不值得深学。这就是持续学习的方法。

    展示物3：Ollama 本地运行演示¶

    # 拉取轻量模型
ollama pull qwen2.5:0.5b

# 运行交互对话
ollama run qwen2.5:0.5b
>>> 你好，请用一句话介绍自己

# 预期输出（模型回复示例）：
# 我是 Qwen2.5，一个由阿里云开发的语言模型，很高兴认识你！

    切换到 Python 代码，展示 OpenAI 兼容接口：

    # 用课程学的 openai SDK 调用 Ollama 本地模型
# 唯一区别：base_url 指向本地
from openai import OpenAI

client = OpenAI(
    api_key="ollama",  # Ollama 不检查 key，随便填
    base_url="http://localhost:11434/v1"
)

response = client.chat.completions.create(
    model="qwen2.5:0.5b",
    messages=[{"role": "user", "content": "你好，请用一句话介绍自己"}]
)
print(response.choices[0].message.content)

    # 运行命令
python call_ollama.py

# 预期输出：
# 我是 Qwen2.5，一个由阿里云开发的语言模型。

    演示要点：重点强调"base_url 改一行，其他代码不变"——学一套 openai SDK，云端和本地模型都能用。
