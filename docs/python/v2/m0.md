<div class="pyv2" data-pyv2-page>
  <h2 style="font-size:20px;">核心观念：AI 时代的三种不可替代能力</h2>
  <p>微课 <a href="../scripts/V001-AI时代为什么学编程/">V001</a> 的核心观点：AI 把「写代码」的成本降到了接近零，但以下三件事它替代不了你：</p>
  <div class="pyv2-lab">
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">能力 ①</span><b>读代码</b>
      <p>AI 生成的代码必须先看得懂，才能判断对与错、安全与不安全。例如 AI 把 API 密钥直接写进源码——不具备读代码能力的人发现不了这类隐患。</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">能力 ②</span><b>调试</b>
      <p>AI 不会一次写对。程序报错或行为异常时，能定位问题、能修复——这是无法外包给 AI 的能力，也是 M6「AI-free 调试日」要专门训练的。</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">能力 ③</span><b>系统设计</b>
      <p>AI 是执行者；做什么、分几个模块、数据如何流动，由人来决定。如同自动驾驶仍要求驾驶员具备接管能力，关键决策必须由人把关。</p>
    </div>
  </div>

  <h3 style="margin:18px 0 8px;">AI 结对编程工作流（五步循环）</h3>
  <p>课堂上那个 10 分钟完成的 AI 聊天网页，过程拆开就是：<b>描述需求 → AI 生成 → 人审查 → 运行验证 → 微调迭代</b>。
  AI 承担了最耗时的「写」环节，但每一步的决策权都在人手中。本课程要教的，正是掌握决策权所需的能力。</p>
</div>
