### [1:00-2:30] int 整数与 float 浮点数

【画面】在编辑器中逐行输入代码，终端同步显示运行结果。打出字幕：① int 整数——无限精度。

【旁白】

第一种，`int`，整数类型。我们在API响应里取出`total_tokens`，值是`40`。用`type()`来看它的类型：

```python
total_tokens = api_response["usage"]["total_tokens"]
print(type(total_tokens))  # <class 'int'>
```

运行，结果是`<class 'int'>`。这说明`40`是一个`int`。整数有什么特点？Python的整数有一个非常强大的特性——无限精度。什么意思？你写`2 ** 100`，就是2的一百次方，别的语言可能溢出报错，Python直接给你算出来，一长串数字，一点不丢精度。

再来看`float`，浮点数，就是带小数点的数。比如我们在算API调用费用的时候：

```python
price_per_1k = 0.001
cost = total_tokens / 1000 * price_per_1k
print(type(cost))   # <class 'float'>
print(cost)         # 4e-05
```

`0.001`是`float`，算出来的`cost`也是`float`。这里有个小知识点，`4e-05`就是科学计数法，等于0.00004。费用的格式化输出下节课专门讲，今天先记住——带小数点的数就是`float`。

一句话区分：没有小数点的数字是`int`，有小数点的是`float`。

### [2:30-4:45] str 字符串——索引、切片与不可变性

【画面】打出字幕：③ str 字符串——不可变序列。从API响应中取出AI回复文本，逐步演示索引、切片、不可变性。终端同步输出。

【旁白】

第三种，也是今天的大头——`str`，字符串。API返回的AI回复就是字符串：

```python
reply = api_response["choices"][0]["message"]["content"]
print(reply)         # 变量是一个装数据的盒子。
print(type(reply))   # <class 'str'>
```

字符串是什么？就是用引号包起来的一段文本。单引号、双引号都行，Python不挑。

字符串最强大的能力是——切片。什么意思？你可以按位置取出里面任意一段字符。Python里从`0`开始数，所以第一个字符的位置是`0`：

```python
print(reply[0])     # 变
print(reply[1])     # 量
```

`reply[0]`取到"变"，`reply[1]`取到"量"。这就是索引。

更实用的是切片，一次取一段：

```python
print(reply[0:5])   # 变量是一
```

`reply[0:5]`取的是从位置0到位置4的字符，注意，左闭右开，包含0，不包含5。这个规则刚开始会觉得别扭，但用多了就习惯了，几乎所有编程语言都这样。

再来看一个特别重要的概念——不可变性。字符串是不可变的，什么意思？你不能修改它里面的某个字符。我来演示：

```python
reply[0] = "我"  # TypeError: 'str' object does not support item assignment
```

看，报错了。Python告诉你，字符串不支持修改单个字符。那我想改怎么办？你得创建一个新字符串：

```python
new_reply = "我" + reply[1:]
print(new_reply)  # 我量是一个装数据的盒子。
```

`reply[1:]`表示从位置1开始取到最后。拼接之后得到一个全新的字符串。记住这个结论——字符串不可变，每次"修改"其实是生成了一个新字符串。

### [4:45-5:50] bool 布尔值与 NoneType

【画面】打出字幕：④ bool 只有 True / False　⑤ NoneType 只有 None。在终端演示布尔运算和None的特性。

【旁白】

第四种，`bool`，布尔类型。它只有两个值——`True`和`False`。注意，Python里首字母必须大写，`true`全小写是JSON和JavaScript的写法，在Python里会报错。

API返回里的`finish_reason`值是`"stop"`，这是一个字符串。但程序里我们会大量用到布尔值做判断：

```python
print(type(True))   # <class 'bool'>
print(type(False))  # <class 'bool'>
print(40 > 28)      # True
```

`40 > 28`的结果就是`True`，它是一个`bool`。

最后一种，`NoneType`，它只有一个值——`None`。`None`在JSON里叫`null`，到了Python就叫`None`。它表示"什么都没有""空""未定义"。比如一个API请求失败了，没有返回数据，那个变量就会被赋值为`None`：

```python
print(type(None))  # <class 'NoneType'>
```

记住两点：JSON的`null`在Python里是`None`，首字母大写；`None`和`0`不一样——`0`是有值的，值是零；`None`是压根没有值。

### [5:50-7:00] 一切皆对象 + 完整闭环演示

【画面】打出字幕：一切皆对象。运行完整脚本，终端一次性输出所有类型验证结果，形成闭环。

【旁白】

到这里五种类型都讲完了，但我还想说一个Python的核心理念——一切皆对象。什么意思？你看，`type(42)`返回的是`<class 'int'>`，`type("hello")`返回的是`<class 'str'>`。在Python的世界里，整数是对象，字符串是对象，布尔值是对象，连`None`都是对象。每个对象都有自己的类型，`type()`就是查类型的工具。

养成一个习惯，看到任何一段数据，先问自己——它是什么类型？这个习惯能帮你避开后面无数的坑。

来，我们把今天的完整代码跑一遍，从API响应里取值、验证类型，形成闭环：

```python
api_response = {
    "model": "deepseek-chat",
    "choices": [
        {
            "index": 0,
            "message": {
                "role": "assistant",
                "content": "变量是一个装数据的盒子。"
            },
            "finish_reason": "stop"
        }
    ],
    "usage": {
        "prompt_tokens": 28,
        "completion_tokens": 12,
        "total_tokens": 40
    }
}

# --- 从API响应取值并验证类型 ---

# 整数 int
total_tokens = api_response["usage"]["total_tokens"]
print(f"总token数: {total_tokens}, 类型: {type(total_tokens)}")

# 浮点数 float
price_per_1k = 0.001
cost = total_tokens / 1000 * price_per_1k
print(f"调用费用: {cost}, 类型: {type(cost)}")

# 字符串 str——索引与切片
reply = api_response["choices"][0]["message"]["content"]
print(f"AI回复: {reply}, 类型: {type(reply)}")
print(f"前5个字: {reply[0:5]}")

# 布尔值 bool
is_stop = api_response["choices"][0]["finish_reason"] == "stop"
print(f"是否正常结束: {is_stop}, 类型: {type(is_stop)}")

# NoneType
nothing = None
print(f"空值: {nothing}, 类型: {type(nothing)}")
```

运行！你看，所有类型一清二楚。整数是`int`，费用是`float`，回复文本是`str`，判断结果是`bool`，空值是`NoneType`。这就是你的第一个"类型感知"程序。

## 演示操作清单

> 以下为录制时需要敲入的完整代码，可直接复制到 `types_demo.py` 运行，无需联网。

```python
api_response = {
    "model": "deepseek-chat",
    "choices": [
        {
            "index": 0,
            "message": {
                "role": "assistant",
                "content": "变量是一个装数据的盒子。"
            },
            "finish_reason": "stop"
        }
    ],
    "usage": {
        "prompt_tokens": 28,
        "completion_tokens": 12,
        "total_tokens": 40
    }
}

# === ① int 整数 ===
total_tokens = api_response["usage"]["total_tokens"]
print(type(total_tokens))   # <class 'int'>

# int 无限精度演示
big_number = 2 ** 100
print(big_number)           # 1267650600228229401496703205376

# === ② float 浮点数 ===
price_per_1k = 0.001
cost = total_tokens / 1000 * price_per_1k
print(type(cost))           # <class 'float'>
print(cost)                 # 4e-05

# === ③ str 字符串 ===
reply = api_response["choices"][0]["message"]["content"]
print(reply)                # 变量是一个装数据的盒子。
print(type(reply))          # <class 'str'>

# 索引
print(reply[0])             # 变
print(reply[1])             # 量

# 切片（左闭右开）
print(reply[0:5])           # 变量是一

# 不可变性——取消注释验证报错
# reply[0] = "我"  # TypeError: 'str' object does not support item assignment

# 正确做法：创建新字符串
new_reply = "我" + reply[1:]
print(new_reply)            # 我量是一个装数据的盒子。

# === ④ bool 布尔值 ===
print(type(True))           # <class 'bool'>
print(type(False))          # <class 'bool'>
print(40 > 28)              # True

# === ⑤ NoneType ===
print(type(None))           # <class 'NoneType'>

# === 完整闭环：取值 + 类型验证 ===
print("--- 类型速查 ---")
print(f"总token数: {total_tokens}, 类型: {type(total_tokens)}")
print(f"调用费用: {cost}, 类型: {type(cost)}")
print(f"AI回复: {reply}, 类型: {type(reply)}")
print(f"前5个字: {reply[0:5]}")
is_stop = api_response["choices"][0]["finish_reason"] == "stop"
print(f"是否正常结束: {is_stop}, 类型: {type(is_stop)}")
print(f"空值: {None}, 类型: {type(None)}")
```
