分支：让程序做决定

# 按 token 消耗分级——来自真实的 API 日志场景
for log in api_logs:
    if log["tokens"] < 50:
        level = "轻量"
    elif log["tokens"] <= 200:
        level = "正常"
    else:
        level = "高消耗"

# 组合条件：高消耗 且 调用失败
if log["tokens"] > 200 and not log["ok"]:
    print("⚠ 需要排查：", log)
  • Python 用缩进表示代码块（其他语言用花括号）——缩进错了就是语法错误
  • and / or / not 组合条件；elif 链代替其他语言的 switch

循环：重复做事

# for：遍历已知集合
for i in range(5):
    print(i)        # 0 1 2 3 4

# while：满足条件就一直做
while True:
    q = input("你：")
    if q == "退出":
        break           # 跳出整个循环
    reply(q)
循环两大杀手
  • off-by-one：range(5) 是 0–4，不是 1–5
  • 死循环：忘写 break / 条件永真 → Ctrl+C 终止
break vs continue break 跳出循环；continue 跳过本轮进入下一轮。

函数：给逻辑起名字

def estimate_cost(tokens: int, price: float = 0.001) -> float:
    """估算一次 API 调用的费用（元）。

    >>> estimate_cost(730)
    0.73
    """
    return tokens * price / 1000

cost = estimate_cost(730)          # 位置参数
cost = estimate_cost(tokens=730)     # 关键字参数
  • 为什么需要函数：换一份数据再跑，不必复制粘贴代码
  • 默认值参数让调用更省事；*args / **kwargs 收集任意数量参数——读 AI 代码必备
  • lambda：一行匿名函数，常当 key 用：max(logs, key=lambda l: l["tokens"])

函数契约四要素

①名字它做什么 count_words 而不是 func1——名字即文档，AI 也靠名字理解代码。
②参数它需要什么 类型 + 含义 + 默认值：text: str, topk: int = 3
③返回值它给出什么 返回 dict 还是 list？空输入返回什么？异常时抛还是返 None？
④示例怎么用 docstring 里放 doctest 示例——既是文档也是测试。
好的函数契约 = 好的 prompt。把契约四要素写给 AI，AI 就能一次写出正确的函数； 反过来，看不懂 AI 函数时，先问自己「它的契约是什么」。
