# 2.1 基本概念——安装 Python

## 内容梗概

本节手把手带大家完成 Python 开发环境的配置：从官网下载安装包、选择正确版本、运行安装程序并勾选关键选项。老师逐个解释了下载页面上各类安装文件的区别（源代码、mac 版、Windows 32/64 位、在线/离线安装包等），并演示了默认安装与自定义安装路径两种方式。这是全课程第一个动手操作环节。

## 知识点详解

### 下载 Python 安装包

- 进入 Python 官网，点 "Downloads"，选择版本进入下载页（约 00:37）。
- Python 更新很快：老师截图时最新为 3.8.2，同期还发布了 3.7.7（约 01:50）。课程以 3.8.2 为例。
- 如果之前已装过 Python 或通过 Anaconda 装过环境，可暂不重复安装（约 02:31）。
- 关于 TensorFlow：有同学提到 3.7/3.8 用不了 TensorFlow（深度学习框架）。本课程不涉及深度学习，无影响；若兼顾其他课程，装 3.6/3.5 低版本也能跟上本课（约 03:04）。

### 下载页面各类文件的区别

- 页面上方文件均无需理会：两个压缩包是 Python 源代码，另有 macOS 安装文件和 Windows 帮助文档（约 03:34）。
- 下方六个 Windows 安装文件分两组（约 04:07）：
  - 带 **x86-64** 字样的三个：适用于 64 位 Windows；
  - 其余三个（x86）：适用于 32 位 Windows。
- 查看系统位数：打开资源管理器 → 右键"此电脑"→ 属性，查看"64 位操作系统 / 32 位操作系统"（约 04:37）。
- 每组三个文件的区别（约 05:06）：
  - **executable installer**：离线安装包，约 27–28 MB，下载后直接安装，**选这个**；
  - **web-based installer**：基于网络的安装包，安装过程中还要联网下载，不推荐；
  - 另一个是压缩包形式，不用。

### 安装过程

- 双击安装包后，**务必勾选 "Add Python 3.8 to PATH"**（约 06:23）：把 Python 安装目录添加到系统环境变量 PATH 中。
- 两种方式（约 09:48）：
  - **默认安装**：勾选 Add to PATH 后直接点 Install，装在默认路径，无需改动；
  - **自定义安装（Customize installation）**：可改安装路径。中间选项页保持默认（含 Python 文档、第三方库安装工具 pip、自带开发环境 IDLE 与测试套件），点 Next 后在路径处填写目标目录或点 Browse 选择（例如装到 `D:\python`），再点 Install。
- 安装完成后即可使用 Python 自带的开发环境写代码（约 12:00）。

### 延伸问题

- 有同学问"为什么学这门语言还要专门下载安装包"——这涉及编译型与解释型语言的原理，在 2.3 节详细解答（约 06:37）。

## 示例与演示

- 全程实操演示：打开官网 → 选版本 → 下载 executable installer → 双击安装 → 勾选 Add Python 3.8 to PATH → 演示自定义安装到指定目录（Browse 选择文件夹）→ 安装成功。
- 因官网下载较慢，老师把安装包发到课程群供直接下载。

## 重点与难点

- **最容易出错的一步：忘记勾选 "Add Python 3.8 to PATH"**，会导致后续无法在命令行直接使用 Python。
- 区分 64 位（x86-64）与 32 位（x86）安装包，选错无法安装或运行异常。
- 优先选 executable installer（离线包），不要选 web-based installer。
- 已经装过 Python 或 Anaconda 的同学不要盲目重装。
