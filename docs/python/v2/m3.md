<div class="pyv2" data-pyv2-page>
  <h2 style="font-size:20px;">L15 全链路迷你版（浏览器可运行）</h2>
  <p>requests / pandas 依赖本地环境，但「拿到 JSON → 清洗统计 → 输出结论」的思路可以先在这里跑通。
  这段代码模拟了 L15 课堂对「电影评分数据」的处理流程：</p>
  <div class="py-playground" data-py-title="数据处理全链路：清洗 → 统计 → 结论">
    <textarea>import json

# 模拟从 API 抓回来的电影数据（含脏数据）
raw = '''
[
  {"title": "流浪地球2", "score": 8.3, "year": 2023},
  {"title": "满江红", "score": 7.0, "year": 2023},
  {"title": "奥本海默", "score": 8.9, "year": 2023},
  {"title": "数据缺失", "score": null, "year": 2023},
  {"title": "封神", "score": 7.8, "year": 2023},
  {"title": "消失的她", "score": 6.4, "year": 2023}
]
'''
movies = json.loads(raw)

# 1) 清洗：丢弃 score 缺失的记录（Pandas 里叫 dropna）
clean = [m for m in movies if m["score"] is not None]

# 2) 统计：平均分、最高分
avg = sum(m["score"] for m in clean) / len(clean)
best = max(clean, key=lambda m: m["score"])

# 3) 分级统计（Pandas 里叫 groupby）
buckets = {"佳作(>=8)": 0, "良好(7-8)": 0, "一般(<7)": 0}
for m in clean:
    if m["score"] >= 8: buckets["佳作(>=8)"] += 1
    elif m["score"] >= 7: buckets["良好(7-8)"] += 1
    else: buckets["一般(<7)"] += 1

print(f"有效影片 {len(clean)} 部，平均分 {avg:.1f}")
print(f"最高分: {best['title']} ({best['score']})")
print("分级:", buckets)
print("ASCII 柱状图:")
for name, n in buckets.items():
    print(f"  {name:　<10} {'█' * (n * 3)}")
</textarea>

  <h2 style="font-size:20px;">爬虫礼仪三问（L14）</h2>
  <div class="pyv2-tl">
    <div class="pyv2-tl-item" data-anim><b>能不能爬？</b><span class="meta">robots.txt</span><p>先访问 域名/robots.txt 看站长是否允许；Disallow 的路径不要碰。法律上还要尊重网站条款与个人信息保护法。</p></div>
    <div class="pyv2-tl-item" data-anim><b>该不该爬？</b><span class="meta">频率与压力</span><p>加 time.sleep()、避开高峰；你的每一次请求都是别人的服务器成本。课堂演示过爬太快被封 IP 的现场翻车。</p></div>
    <div class="pyv2-tl-item" data-anim><b>用来干什么？</b><span class="meta">用途边界</span><p>学习研究可以；商用、转卖、爬隐私数据不行。数据的使用比获取更需要注意边界。</p></div>
