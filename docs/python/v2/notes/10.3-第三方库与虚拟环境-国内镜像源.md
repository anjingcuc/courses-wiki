# 10.3 第三方库与虚拟环境——国内镜像源

## 内容梗概

本节解决 pip 安装第三方库时"下载慢甚至超时失败"的问题。老师先结合上节的包管理机制解释原因：安装过程涉及索引服务器和文件服务器，二者都在境外，所以即使访问 pypi.org 很快，下载文件也可能极慢。解决方法是把源换成国内机构（阿里云、清华大学等）提供的镜像服务器。随后分别演示了**临时**（`-i` 参数）和**全局**（pip 配置文件）两种修改方式，并覆盖 Windows 与 macOS/Linux 两个平台，最后建议大家都全局改成国内镜像源。

## 知识点详解

### 1. 为什么下载慢——两台服务器的视角（约 00:00–00:56）
- 回顾上节：安装一个包涉及**两台服务器——索引服务器和文件服务器**。
- 常见困惑：访问 pypi.org（索引服务器）很快，但安装过程特别慢——因为实际下载走的是境外的文件服务器。
- 解决思路：**修改镜像源**，把这两个服务器换成国内的镜像（阿里、清华大学等大厂/机构为国内用户提供的便利服务）。

### 2. 镜像源地址怎么来（约 01:54–02:20）
- 谷歌搜索"pip 国内镜像源"即可找到阿里云等镜像地址。
- 在校园网环境下用**清华源**通常更快。

### 3. 临时修改：`-i` 参数（约 02:20–03:59）
- 现场对比：未换源时下载只有约 70KB/s；换源后快得进度条都没看清就装完了。
- 用法：`pip install -i 镜像源地址 包名`。
- `-i` 全称是 `--index-url`，即"索引的 URL"；安装输出中的 `Looking in indexes: ...` 即表示在该索引服务器上查找包。
- 老师强调：命令行参数要**理解意思再去记**，理解了自然记得住。

### 4. 全局修改（Windows）（约 03:59–05:44）
- 在 `%AppData%` 目录下新建 `pip` 文件夹（呼应上节讲的 `%AppData%` 快捷展开，此处正是铺垫）。
- 在 `pip` 文件夹中新建 `pip.ini`，用 VS Code 打开，写入配置并保存（Ctrl+S）：
  ```ini
  [global]
  index-url = 镜像源地址
  trusted-host = 镜像源域名
  ```
- 配置含义：`[global]` 表示全局配置；`index-url` 即索引服务器地址；`trusted-host` 是安全机制，表示信任该域名（主机），从其下载的包允许安装。
- 验证：卸载刚装的库后重新 `pip install`（不带 `-i`），输出仍出现 `Looking in indexes: 镜像地址`，说明配置文件生效。

### 5. 全局修改（macOS / Linux）（约 06:13–08:14）
- 用 Windows 的 WSL（Linux 子系统）演示，macOS 与 Linux 操作一模一样。
- 在用户目录（home 目录，`cd ~` 进入，波浪线 `~` 即用户目录）下：
  - `mkdir .pip` 创建 `.pip` 目录；
  - 在其中创建 `pip.conf` 文件（注意后缀：Windows 配置文件一般是 `.ini`，Linux/mac 一般是 `.conf`）；
  - 用习惯的编辑器（如 VS Code）把同样的配置粘贴进去保存。
- 逻辑与 Windows 完全一致，只是操作路径和文件名不同。

### 6. 建议与常见问题（约 08:14–10:28）
- 老师建议：直接**全局**改成阿里云、清华或任何喜欢的镜像源。
- 不改的话不仅慢，还可能因一定时间内连不上/没速度而**超时（timeout）**导致安装失败。
- 排错口诀：看到 `timeout` 报错就要联想到是**网络问题**。

## 示例与演示

- 速度对比实验：默认官方源安装某库约 70KB/s；加 `-i` 阿里云镜像后瞬间装完。
- Windows 下创建 `%AppData%\pip\pip.ini`，删除已装库后重新安装验证全局配置生效。
- 通过 WSL 演示 Linux/mac 下 `cd ~` → `mkdir .pip` → 创建 `pip.conf` 的完整流程。

## 重点与难点

- 分清两类服务器：索引慢还是文件下载慢，根源都是境外服务器，换镜像源一并解决。
- `-i` = `--index-url`，理解参数含义比死记重要。
- 全局配置三要素：正确的目录（`%AppData%\pip` 或 `~/.pip`）、正确的文件名（`pip.ini` / `pip.conf`）、配置内容（`[global]` + `index-url` + `trusted-host`）。
- `timeout` 报错 = 网络问题，优先考虑换源。
