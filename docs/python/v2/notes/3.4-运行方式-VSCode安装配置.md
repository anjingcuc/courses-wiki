# 3.4 运行方式——VSCode 安装配置

## 内容梗概

本课讲解 VSCode 的安装与配置，后续课程所有代码都将基于 VSCode 编写。老师先解释了为什么不用 IDLE（配色、字体、功能太简单）以及为什么不用 PyCharm 而用 VSCode（开源免费、支持多种语言；PyCharm 专业版收费，学生可用学校邮箱申请教育版，课程不强制也不讲解其配置）。随后演示了 VSCode 的下载安装（安装选项建议全勾，否则右键菜单没有"通过 Code 打开"），以及两个必装扩展：微软官方的中文语言包（Chinese）和 Python 扩展。最后详细介绍了 VSCode 界面要点：未保存标记（小圆圈）、F5 运行、左下角 Python 解释器版本选择，以及右下角的编码（推荐 UTF-8）、换行符（CRLF/LF）和语言模式设置，并专门提醒了"微信复制代码换行符异常导致无法运行"的经典坑。结尾对第 3 章做了总结并预告下节课讲数据类型。

## 知识点详解

### 为什么用 VSCode

- IDLE 只是让你学习的简单开发环境，配色、字体、方便的功能都没有（约 00:50）。
- VSCode 开源免费；PyCharm 专业版收费（有免费的社区版），学生可用学校邮箱申请教育版（免费专业版），用 PyCharm 不阻止，但课程只讲 VSCode（约 01:48）。
- VSCode 支持多种语言：HTML、JavaScript、PHP 等都能写，不用为每种语言装一个 IDE（约 02:13）。

### 下载与安装

- 访问官网链接下载安装包，直接点 Download 即可（约 02:18）。
- 安装过程中的各种选项推荐全部勾上：勾选后右键菜单会有"通过 Code 打开"选项，讲课时的操作依赖这个菜单；不勾也能用（可以把文件拖进 VSCode），但操作会和课上不一致（约 02:23）。

### 必装两个扩展（Extensions）

- 刚装好的 VSCode 是英文界面且写 Python 不好用，需要装两个扩展（约 06:44）：
  - 中文语言包：扩展商店搜索 `Chinese`，安装微软（Microsoft）官方汉化包，点 Install 后 Restart 重启即变成中文（约 07:33）。
  - Python 扩展：搜索 `python`，只装最上面那个微软官方出的、名字就叫 "Python" 的扩展（约 08:47）。

### 界面要点与常用操作

- 放大界面：按住 `Ctrl` 按 `=`（等于号/加号键）整体放大界面，方便分享（约 10:48）。
- 未保存标记：文件标签上的叉叉变成小圆圈表示有修改未保存，未保存时运行不会生效；`Ctrl + S` 保存后再运行（约 11:15）。
- 运行代码：装了 Python 扩展后，点右上角小箭头（Run Python File）即自动运行当前文件，快捷键 `F5`（约 13:11）。
- 解释器选择：左下角显示当前使用的 Python 版本（如 Python 3.8.x 64 位），点一下可列出电脑上检测到的所有 `python.exe`，按需要切换版本，F5 运行时用所选版本执行（约 14:28）。

### 状态栏三个重要设置（右下角）

- 编码（约 16:07）：当前文件的编码方式。中文 Windows 默认编码一般是 GBK（"国标"拼音首字母，即国家标准），但推荐 UTF-8；Python 3 默认字符串用 UTF-8（unicode）编码。编码的详细原理留待讲二进制文件时解释。此处可以用某种编码重新打开文件，或用新编码保存文件。
- 换行符 CRLF/LF（约 18:35）：换行也要转成二进制存储，Windows（CRLF，即 0D 0A）与 Linux/macOS（LF，即 0A）的表示方式不同。Windows 下保持 CRLF 即可，不要动。
- 语言模式（约 21:46）：VSCode 通过后缀名自动识别文件语言并做代码高亮（关键字彩色显示）。`.txt` 文件被当纯文本不高亮，把后缀改成 `.py` 等对应语言后缀即有高亮。

### 经典坑：微信复制代码运行报错

- 现象：从微信复制的 Python 代码粘贴到 VSCode 里怎么都运行不了，报错的代码怎么看都没错（约 20:06）。
- 原因：换行不一致，微信会在文本尾巴上添加莫名其妙的换行符，Python 解释器不认识。
- 解决：把所有换行手动删掉重新回车一遍即可（约 20:54）。

### 本课总结（第 3 章小结，约 24:22）

1. 下载 Python 并配置好环境变量（回顾为什么要配环境变量）。
2. 解释型语言与编译型语言的区别：Python 是解释型语言。
3. 推荐的运行方式：命令行中 `python 源文件名` 的方式。
4. Python 2 已停止维护，课程使用 Python 3。
5. 用 VSCode 作为集成开发环境。

## 重点与难点

- 未保存（小圆圈）就运行是新手最常踩的坑，看到圆圈就 `Ctrl + S`。
- 从微信等聊天工具复制的代码可能因换行符异常而无法运行，解决办法是把换行全部手动重打一遍。
- 多版本 Python 共存时，要确认 VSCode 左下角选中的解释器版本。
- 编码推荐 UTF-8；Python 3 默认使用 UTF-8/unicode 编码字符串；GBK 是中文 Windows 的常见默认编码。
- 安装 VSCode 时选项全勾，保证右键有"通过 Code 打开"。
