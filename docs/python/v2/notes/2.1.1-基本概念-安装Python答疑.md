# 2.1.1 基本概念——安装 Python 答疑

## 内容梗概

本节是安装 Python 后的现场答疑，集中解答同学在微信群里反馈的两类安装问题。第一类是把 Python 装到 C 盘根目录或 Program Files 下时出现的写入错误/拒绝访问，原因是这些位置需要管理员权限；老师强烈建议改用默认的用户目录路径，或自建一个无中文无空格的专用文件夹。第二类是安装界面末尾的 "Disable path length limit" 选项的作用，即可解除 Windows 默认 260 字符的路径长度限制。

## 知识点详解

### 错误 1：Error writing to file / 拒绝访问

- 错误信息大意：`Error writing to file C:\python38... verify that you have access to that directory`（约 00:44）。再次印证要"勇于看英文"。
- **原因**：把 Python 直接装到 C 盘根目录（或 Program Files 目录），这些位置需要管理员权限，默认情况下普通安装没有权限写入（约 01:15）。
- 技术上可以右键"以管理员身份运行"安装程序强行安装，但**强烈不推荐**（约 01:38）：装在管理员权限目录下，以后每次操作都可能要管理员权限，很麻烦。
- 正确做法：
  - 只有 C 盘时直接用**默认安装路径**（约 02:09）：默认路径在当前用户的用户文件夹下（如用户"安静"对自己的用户目录天然有权限），无需管理员权限。
  - 默认路径的优点：不含中文和空格、是独立文件夹，满足要求（约 03:12）。
  - 若**用户名本身是中文或含空格**（默认路径会带上中文用户名）：可在 C 盘下自建一个专门目录（如 `Development Environment`），把 Python 装进去，该目录不需要管理员权限（约 03:44）。
- 同类问题：报"拒绝访问"也是装到了 C 盘根目录或 Program Files 下的某个位置（约 02:40）。

### 问题 2：Disable path length limit 是什么

- Windows 系统默认限制路径字符串最长 260 个字符（对应宏定义 MAX_PATH）（约 04:52）。
- 安装末尾的 **Disable path length limit** 选项可去掉这一长度限制（约 05:12）。
- 是否启用可自行选择：去掉没问题，不去掉也不影响本课程；老师自己选择去掉（约 05:29）。

## 重点与难点

- 安装路径三原则：**不要装在 C 盘根目录 / Program Files（需管理员权限）、路径不要有中文和空格、用独立文件夹**。
- 用户名是中文的同学要格外注意默认路径里会含中文，需自定义安装目录。
- 遇到英文报错不要慌，读懂报错关键词（access、directory）即可定位问题。
