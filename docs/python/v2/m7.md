<div class="pyv2" data-pyv2-page>
  <h2 style="font-size:20px;">AI 时代的程序员能力模型</h2>
  <p>L47 的核心一页——四个维度相乘而非相加（任何一项为零都会拖垮整体）：</p>
  <div class="pyv2-lab">
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">基础</span><b>编程与计算机基本功</b>
      <p>数据结构与算法直觉、网络与系统概念、读代码能力——AI 能力越强，判断其输出是否正确的能力越重要。</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag v">AI 协作</span><b>驾驭模型的工程能力</b>
      <p>Prompt 设计、RAG/Agent 架构选型、输出验证、成本与风险评估——本课程 M5 的全部内容。</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">工程化</span><b>把演示原型变成产品的能力</b>
      <p>测试、版本控制、模块化、部署运维——M4 与 M6 反复打磨的部分。</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag v">领域知识</span><b>懂业务才能定义问题</b>
      <p>媒体、金融、医疗……AI 是通用工具，价值落在具体领域。领域知识也是系统设计能力的重要支撑。</p>
    </div>
  </div>
</div>

<div class="pyv2" data-pyv2-page>
  <h2 style="font-size:20px;">结课后的四条深入路线</h2>
  <div class="pyv2-tl">
    <div class="pyv2-tl-item" data-anim><b>Web / 后端方向</b><span class="meta">FastAPI → 数据库 → Docker → 云</span><p>把期末项目升级成真正的多用户服务；深入异步编程与性能调优。</p></div>
    <div class="pyv2-tl-item" data-anim><b>数据方向</b><span class="meta">SQL → Pandas 进阶 → 数仓/BI</span><p>M3 的数据处理链路专业化；配合可视化与统计分析。</p></div>
    <div class="pyv2-tl-item" data-anim><b>AI 工程/研究方向</b><span class="meta">RAG/Agent 深入 → 微调 → 模型原理</span><p>读 transformer 论文、玩 Ollama 本地模型、HuggingFace 开源生态。</p></div>
    <div class="pyv2-tl-item v" data-anim><b>产品方向</b><span class="meta">场景洞察 → 原型 → 迭代</span><p>用 AI 结对开发把想法快速变成可用产品——技术是手段，解决问题才是目的。</p></div>
  </div>
