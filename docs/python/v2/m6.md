<div class="pyv2" data-pyv2-page>
  <h2 style="font-size:20px;">项目池（五选一）</h2>
  <p>每个项目都有真实用户场景、前后端 + AI 完整技术栈、足够的扩展空间。共同要求：<b>能在答辩中说清每一行代码的作用</b>。</p>
  <div class="pyv2-lab">
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">RAG</span><b>AI 知识库助手</b>
      <p>上传文档 → 切分向量化 → 检索问答。技术栈：FastAPI + Embedding + LLM + 前端。难度 ★★★</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">Function Calling</span><b>智能学伴</b>
      <p>多轮对话 + 工具调用（出题/判题/讲解）。技术栈：FastAPI + LLM + 出题逻辑。难度 ★★★</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag v">多模态</span><b>AI 创意工坊</b>
      <p>文生图 + TTS 朗读 + 作品集管理。技术栈：FastAPI + 图片生成 API + TTS。难度 ★★★☆</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag v">NL2Code</span><b>智能数据分析师</b>
      <p>自然语言查数据：用户提问 → LLM 生成 Pandas 代码 → 执行 → 可视化。难度 ★★★☆</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">RAG + Agent</span><b>AI 客服机器人</b>
      <p>知识库检索 + 多轮对话 + 工具调用（查订单/转人工）。难度 ★★★★</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag g">自拟</span><b>自定义选题</b>
      <p>有真实场景、用到 AI 核心 API、技术栈完整即可与教师商定自拟。</p>
    </div>
  </div>
</div>

<div class="pyv2" data-pyv2-page>
  <h2 style="font-size:20px;">14 节课的项目周期</h2>
  <div class="pyv2-tl">
    <div class="pyv2-tl-item" data-anim><b>L31 启动</b><span class="meta">选题与需求</span><p>选题分组、需求文档（用户/问题/功能清单/技术选型）、MVP 定义。交付：项目提案。</p></div>
    <div class="pyv2-tl-item" data-anim><b>L32 架构</b><span class="meta">系统设计</span><p>数据流图、模块划分、API 设计、AI 能力选型（对话/RAG/Agent/多模态）、技术风险识别。交付：架构文档 + 接口定义。</p></div>
    <div class="pyv2-tl-item" data-anim><b>L33–34 冲刺一</b><span class="meta">后端与 AI 核心</span><p>Standup（2 分钟/组）→ 开发 → 教师巡场。搭 FastAPI 骨架、实现 AI 核心功能、数据模型。</p></div>
    <div class="pyv2-tl-item" data-anim><b>L35–36 冲刺二</b><span class="meta">前端与整合</span><p>前后端联调是最大的「坑」时间——CORS、数据格式、异步流式渲染。</p></div>
    <div class="pyv2-tl-item v" data-anim><b>L37 AI-free 调试日</b><span class="meta">禁用一切 AI</span><p>只用 print / 日志 / 断点 / 读报错修自己项目的 bug，建立「无 AI 时我能做什么」的肌肉记忆。</p></div>
    <div class="pyv2-tl-item" data-anim><b>L38 Bug Bash</b><span class="meta">互相测试</span><p>全班互相体验对方 demo、提交 issue——用户视角的质量意识。</p></div>
    <div class="pyv2-tl-item" data-anim><b>L39 部署</b><span class="meta">上线概念</span><p>本地完整运行演示为底线，云部署为加分项；环境变量管理。微课 V054。</p></div>
    <div class="pyv2-tl-item" data-anim><b>L40–41 打磨</b><span class="meta">文档与录屏</span><p>重构、README（介绍/安装/使用/技术栈）、AI 协作日志整理、演示准备。</p></div>
    <div class="pyv2-tl-item v" data-anim><b>L42–43 答辩</b><span class="meta">8–10 分钟/组</span><p>5 分钟演示 + 3-5 分钟问答，全班互评。评分维度：功能完整性 / 技术深度 / 用户体验 / 代码质量 / AI 协作意识。</p></div>
    <div class="pyv2-tl-item" data-anim><b>L44 复盘</b><span class="meta">优秀代码审查</span><p>选 2-3 组深度复盘；读别人的代码是最高效的学习。微课 V055。</p></div>
  </div>
</div>

<div class="pyv2" data-pyv2-page>
  <h2 style="font-size:20px;">答辩「灵魂三问」</h2>
  <div class="pyv2-lab">
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">问一</span><b>随机指一行 AI 生成的代码：这是干什么的？</b>
      <p>答不出 = 该行所在功能计 0 分。这不是刁难——读代码是课程第一能力锚点。</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">问二</span><b>如果去掉 AI 辅助，你能独立写出哪部分？</b>
      <p>诚实回答即可：哪些是你写的、哪些是 AI 生成你审查过的、哪些你还看不懂——协作日志就是为此准备的。</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">问三</span><b>你最自豪的一个功能是怎么实现的？</b>
      <p>讲清「需求 → 方案取舍 → 踩坑 → 解决」的完整链路，比堆功能数量更有价值。</p>
    </div>
  </div>
</div>
