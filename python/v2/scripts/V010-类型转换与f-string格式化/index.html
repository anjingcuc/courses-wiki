    逐字稿¶

    [0:00-0:30] 开场 Hook¶

    【画面】屏幕中央大字弹出 print("730" + 1)，紧接着红色报错信息 TypeError 占满屏幕，配上"啪"的音效。然后弹出标题"类型转换与 f-string 格式化"。

    【旁白】

    "730"加1，你觉得等于几？731？在 Python 里，答案是——报错。看到这个红字没有？TypeError，类型错误。为什么？因为引号里的"730"是字符串，不是数字，Python 认为字符串只能跟字符串拼，不能跟数字加。这个坑，每个 Python 新手都踩过，今天我们就把它彻底填平。

    [0:30-2:15] 类型转换三兄弟：int / float / str¶

    【画面】左边贴出上节课用过的 API 响应 JSON，高亮 total_tokens: 40。右边打开 Python 终端，逐行敲代码，每行结果实时弹出。敲到 int("3.14") 时切换到报错画面，再切回终端演示正确写法。

    【旁白】

    上节课我们从 API 响应里取出了 token 数，还用 type() 验证了类型。但实际开发中，你拿到的数据不一定都是你想要的类型。

    比如你从配置文件里读出来的 token 数，很可能是个字符串"40"。你拿它去做运算，啪，又报错了。再比如用户在命令行输入的数字，input 函数返回的永远都是字符串，不管你输入的是40还是3.14，Python 都当文本处理。

    怎么救？用类型转换。Python 给你三个内置函数：int() 转整数，float() 转小数，str() 转字符串。

    看屏幕，我逐行敲给你看。int("40")，把字符串"40"变成整数40，结果是40，类型是int。这就对了，可以做算术了。

    float("3.14")，把字符串"3.14"转成浮点数，结果是3.14。

    str(42)，反过来，把数字42变成字符串"42"。什么时候用？比如你想把数字拼到一句话里输出，就需要先转成字符串。

    但有个坑你一定会踩：int("3.14")，直接把"3.14"这个字符串转整数，会怎样？报错！ValueError，invalid literal for int。因为 int 没法直接从"3.14"里抠出3。正确写法是先转 float 再转 int：int(float("3.14"))，先变成3.14，再截掉小数变成3。记住这个两步走，能帮你省掉很多报错。

    记住口诀：转换之前先看类型，字符串带小数点就先 float 再 int。

    [2:15-3:30] "字符串数字"陷阱——亲手踩一次¶

    【画面】VSCode 里打开一个 trap.py 文件，逐行写代码、逐行运行。报错信息放大高亮，配上注释 # ✗ TypeError 和 # ✓ 正确。两种修复方式分屏对比。

    【旁白】

    现在我们亲手踩一下这个坑，加深印象。

    看这段代码。第一行，tokens_str = "730"，注意，带引号，这是字符串。第二行，result = tokens_str + 1。运行——报错！TypeError，can only concatenate str to str。Python 说得很清楚：我只能把字符串和字符串拼一起，你给我加个数字，我做不到。

    怎么修？有两种方式，取决于你想要什么结果。

    第一种，你想要的是数学加法，就把"730"转成整数：result = int(tokens_str) + 1，结果731，搞定。

    第二种，你想要的是文本拼接，就把1转成字符串：result = tokens_str + str(1)，但注意，这时候结果是"7301"，是把"730"和"1"拼在一起，不是数学加法。

    所以你得想清楚：我是要做数学运算，还是要做文本拼接？要算术就转 int，要拼文字就转 str。这个选择，以后写代码天天会遇到。

    [3:30-5:30] f-string 格式化——把数据漂亮地输出¶

    【画面】清屏，打开新文件 report.py。先展示目标输出效果（灰色虚框框住三行报表），再逐行写代码实现。写到 {cost:.4f} 时暂停，放大花式标注 .4f 的含义。对比展示 print(cost) 的原始输出 4e-05 与格式化后的输出。

    【旁白】

    类型转换会了，接下来学一个实战利器——f-string，全称叫 formatted string，格式化字符串。

    假设我们调了一次大模型 API，拿到了 token 使用量，想算出这次调用花了多少钱，再打印一份漂亮的报表。怎么把变量的值塞进一句话里？你当然可以用加号拼接，但写起来很麻烦，引号、加号、逗号满天飞，还容易出错。f-string 就是解决这个问题的。

    f-string 的写法很简单：在字符串前面加一个小写 f，然后用花括号把变量名包起来。Python 会自动把变量的值填进花括号的位置。

    看代码。model_name = "deepseek-chat"，total_tokens = 40。

    print(f"模型: {model_name}")，输出就是"模型: deepseek-chat"。花括号里的变量名被替换成了它的值。

    print(f"输入token: {prompt_tokens}, 输出token: {completion_tokens}, 总计: {total_tokens}")，一行搞定，三个变量用逗号隔开就行。你想想，如果用加号拼接，这行代码得写成什么样？引号加号套引号加号，眼花缭乱。这就是 f-string 的威力。

    现在算费用。DeepSeek 的价格大约是每千 token 0.001 元。cost = total_tokens / 1000 * 0.001，结果是0.00004。

    如果直接 print(cost)，输出是 4e-05——这是科学计数法，你的用户看了肯定一脸懵。怎么办？f-string 可以控制输出格式。在变量名后面加一个冒号，再写格式指令。{cost:.4f}，这个 .4f 表示保留四位小数，f 代表 float 浮点数。输出变成了 0.0000，干净多了。

    再演示一个实用的格式：{count:,}，冒号后面加逗号，表示加千分位分隔符。比如 {1000000:,} 输出就是 1,000,000，一眼就能读出来是一百万，不用数零。

    【旁白】

    把今天学的全部串起来，跑一个完整流程。

    代码分五步：第一步，从 API 响应里取出 token 数，这里有输入、输出和总计三个值；第二步，用 type() 确认取出来的是 int 类型——养成"碰数据先看类型"的习惯；第三步，用公式 total_tokens / 1000 * 0.001 计算费用；第四步，用 f-string 把模型名、token 数、费用格式化输出成一份报表；第五步，运行。

    看终端输出：模型 deepseek-chat，输入28，输出12，总计40，本次调用费用0.0000元。

    [6:30-7:00] 小结与引出下集¶

    【画面】知识点卡片依次弹出：① int/float/str 类型转换 ② 字符串数字陷阱 ③ f-string 格式化（.4f / :,）。三张卡片叠在一起。最后底部弹出下集预告文字"V011：数据结构——把一整列数据装起来"。

    【旁白】

    今天三件事，快速回顾。第一，int、float、str 三个函数做类型转换，碰到字符串带小数点就先 float 再 int；第二，"730"加1 会报 TypeError，做算术之前先确认类型，该转就转；第三，f-string 在字符串前面加小写 f，花括号里放变量，冒号后面写格式指令，.4f 保留小数，逗号加千分位。

    【画面】 提问彩蛋。字幕条依次列出三个可以直接照抄去问 Kimi/DeepSeek 的 prompt：

    • ① 请出 6 道 Python 类型转换判断题考我，其中 3 道是 int("3.14") 这种会报错的陷阱题，先别给答案，我答完再逐题讲评。
    • ② 为什么 int("3.14") 报 ValueError，而 int(float("3.14")) 能正常运行？用初学者能听懂的话一步步讲清楚。
    • ③ 给我一张 f-string 格式指令速查表：保留小数、千分位各配一个"错误写法 vs 正确写法"的对比例子。

    【旁白】 照抄这三个 prompt 去问 AI。记住一个原则——报错别只丢给它让它替你改，先让它讲清楚为什么错。它替你改十遍，不如给你讲透一遍，下次这个坑你自己就能绕开。

    今天我们从 API 里取的是单个值——一个 token 数、一个费用。但实际开发中，API 返回的往往是一整列数据：几十条对话记录、几百个搜索结果、上千行日志。怎么把这些数据装起来、批量处理？下集学数据结构，我们不见不散。

    演示操作清单¶

    完整可运行代码¶

    # report.py —— 从 API 响应取值，计算费用，f-string 输出报表

# 步骤①：从 API 响应中取值（模拟数据，无需联网）
prompt_tokens = 28
completion_tokens = 12
total_tokens = 40
model_name = "deepseek-chat"

# 步骤②：验证类型
print(type(total_tokens))   # <class 'int'>

# 步骤③：计算费用（DeepSeek 约 0.001 元/千 token）
price_per_1k = 0.001
cost = total_tokens / 1000 * price_per_1k

# 步骤④：f-string 格式化输出
print(f"模型: {model_name}")
print(f"输入token: {prompt_tokens}, 输出token: {completion_tokens}, 总计: {total_tokens}")
print(f"本次调用费用: {cost:.4f} 元")

    类型转换与陷阱演示¶

    # trap.py —— 类型转换演示

# int() / float() / str() 三兄弟
print(int("40"))        # 40
print(float("3.14"))    # 3.14
print(str(42))          # "42"

# 陷阱①："730" + 1 → TypeError
# tokens_str = "730"
# tokens_str + 1       # ✗ TypeError!

# 修复方式一：转 int 做算术
tokens_str = "730"
print(int(tokens_str) + 1)    # 731 ✓

# 修复方式二：转 str 做拼接
print(tokens_str + str(1))    # "7301"（字符串拼接，不是加法）

# 陷阱②：int("3.14") → ValueError
# int("3.14")            # ✗ ValueError!
print(int(float("3.14")))     # 3 ✓ 先 float 再 int

    f-string 格式指令速查¶

    # 基本用法
name = "deepseek-chat"
print(f"模型: {name}")          # 模型: deepseek-chat

# 保留小数
cost = 0.00004
print(f"费用: {cost:.4f} 元")   # 费用: 0.0000 元
print(f"费用: {cost:.6f} 元")   # 费用: 0.000040 元

# 千分位
count = 1000000
print(f"总调用: {count:,} 次")  # 总调用: 1,000,000 次

# 多变量
a, b, c = 28, 12, 40
print(f"输入{a}, 输出{b}, 总计{c}")  # 输入28, 输出12, 总计40

    录制注意¶

    1. **开场报错画面**要够震撼——红色 TypeError 占满屏幕 + 音效，让观众"肉疼"，记住这个坑。
    2. **类型转换演示**必须在终端逐行敲、逐行出结果，不要一次贴出全部代码，节奏感很重要。
    3. **int("3.14") 报错**是高频口误点，录制时务必先说"直接转整数会报错"，再展示报错画面，最后给 int(float("3.14")) 的正确写法。
    4. f-string 格式指令（.4f、:,）讲解时建议用放大标注或彩色高亮，让观众看清冒号后面的内容。
    5. **费用 0.0000 元**的输出容易让观众困惑（以为算错了），旁白要主动解释："看起来是零，实际是0.00004元，小数点后四位不够显示——这正是格式化的意义。"
    6. 时间紧张时，{count:,} 千分位演示可压缩为一句带过，核心保住类型转换和 {cost:.4f}。
    7. 全程旁白约 1540 字，按 220-250 字/分钟约 6-7 分钟，录制时语速偏慢、留给观众跟敲时间。
    8. 提问彩蛋字幕：提问彩蛋段的 prompt 字幕条需在后期加上，确保观众能暂停照抄。
