  <h3 style="margin:20px 0 8px;">课件使用说明</h3>
  <div class="pyv2-lab">
    <div class="pyv2-demo-card" data-anim>
      <span class="tag">教师</span><b>投影授课</b>
      <p>打开课件按 <b>F</b> 全屏，方向键翻页；带 <b>分步显示</b> 的页面按 → 逐条展开，适合边讲边出。
      URL 形如 <code>#/5</code> 可直达任意一页，便于课前定位。</p>
    </div>
    <div class="pyv2-demo-card" data-anim>
      <span class="tag v">学生</span><b>课堂交互</b>
      <p>手机或电脑打开同一页面：标注「交互」的练习页可直接<b>运行 Python 代码</b>（浏览器内完成），
      小测页点击选项即时判分出解析。</p>
