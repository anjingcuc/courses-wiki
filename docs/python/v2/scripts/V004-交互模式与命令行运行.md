**【画面】** 左边：VSCode 里一个 hello.py 文件，点运行按钮，终端输出文字。右边：命令行里输入 `python hello.py`，同样输出文字。两边并排对比，中间打一个问号。

**【旁白】**
上节课你写了第一行 Python 代码，点了运行按钮就出结果了。但你有没有想过——那个运行按钮背后到底发生了什么？今天我们不用编辑器的按钮，直接在命令行里跑代码。为什么？因为命令行是所有 AI 工具的入口。搞不懂命令行，后面学 Kimi Code、学部署、学调试，全卡住。

### [0:30–2:30] 交互模式：即时反馈的实验场

**【画面】** 录屏：打开终端（Windows: Win+R → cmd；Mac: Terminal）。输入 `python`，进入 `>>>` 交互模式。依次输入 `print("hello")`、`1 + 1`、`"AI" * 3`，每一行立即显示结果。最后输入 `exit()` 退出。

**【旁白】**
先认识 Python 的第一种运行方式——交互模式。打开终端，输入 `python` 回车。看到三个大于号了没？这个 `>>>` 就是 Python 交互模式的标志。意思是 Python 已经准备好听你指挥了。

我们试几行。输入 `print("hello")`，回车，立刻输出 hello。输入 `1 + 1`，回车，输出 2——Python 可以当计算器用。再试一个好玩的：输入 `"AI" * 3`，回车，输出 AIAIAI——字符串乘以数字就是把字符串重复几遍。你看，写一行，执行一行，立刻看到结果。这就是交互模式的魅力：即时反馈，适合试语法、验想法。

但注意：交互模式里写的代码关了就没了，不保存。它是个草稿纸，不是正式文件。退出的话，Windows 按 Ctrl+Z 再回车，Mac 按 Ctrl+D，或者直接输入 `exit()`。

---

### [2:30–5:00] 命令行运行 .py 文件：写代码的正经方式

**【画面】** 录屏：VSCode 中新建 `hello.py`，写入代码。切到终端，先输入 `pwd`（Mac）或 `cd`（Windows 无参数）查看当前目录。然后故意 cd 到错误目录，运行 `python hello.py`，终端报错 `can't open file`。再 cd 到正确目录，运行成功。

**【旁白】**
正式写代码，要用第二种方式——运行 .py 文件。在 VSCode 里新建一个文件，取名 `hello.py`，写几行代码进去：`print("Hello, AI Era!")`，再加一行 `total = sum(range(1, 101))` 和 `print("1 到 100 的和是:", total)`。保存。

现在切到终端。运行之前，第一步永远是——确认你在正确的目录。怎么确认？输入 `pwd`——这是 print working directory 的缩写，会告诉你当前在哪个文件夹。Mac 用 `pwd`，Windows 直接输入 `cd` 不带参数也行。

好，现在我故意先不在正确的目录。我的文件在桌面的 python-learning 文件夹里，但我现在在别的目录。我运行 `python hello.py`——报错了：`can't open file`。这不是代码的错，是 Python 找不到你的文件，因为你所在的目录不对。

怎么办？用 `cd` 命令切换到文件所在的目录。比如 `cd Desktop/python-learning`，然后再 `python hello.py`——这次成功了。输出 Hello, AI Era 和 1 到 100 的和。记住这个流程：cd 到正确目录，再 python 文件名运行。这三步——写代码、保存文件、命令行运行——就是编程最基本的循环。

### [5:00–5:45] 读报错的第一反应

**【画面】** 字幕条弹出报错应对口诀：`报错不可怕 → 读第一行 → 定位问题`。配两个常见报错截图：`can't open file` 和 `IndentationError`。

**【旁白】**
刚才那个报错，我再强调一句。初学者看到红色报错容易慌，其实报错是信息，不是灾难。看到报错，第一步：读第一行。大部分报错第一行就告诉你问题是什么。`can't open file` 就是文件没找到，`NameError` 就是变量名拼错了，`IndentationError` 就是缩进不对。养成习惯：看到报错先读，别急着关窗口。

**【画面】** 字幕条/动画展示三步循环：`① 写代码（VSCode）` → `② 保存 .py 文件` → `③ 命令行 cd + python 运行`。随后弹出练习任务清单。

**【旁白】**
最后把今天的东西收个尾。Python 有两种运行方式：交互模式是草稿纸，写一行跑一行，适合试验；.py 文件是正式文件，cd 过去用 python 命令运行。写代码的基本循环就是三步：写、存、跑。你的课后练习：在桌面试着建一个文件夹，写一个 first.py，用命令行跑起来。如果你能独立完成，说明你已经跨过了命令行这道坎。

## 演示操作清单

### 交互模式

```bash
# 打开终端
# Windows: Win+R → cmd
# Mac: Terminal

python            # 进入交互模式（Mac 用 python3）
# >>> print("hello")
# hello
# >>> 1 + 1
# 2
# >>> "AI" * 3
# 'AIAIAI'
# >>> exit()     # 退出：Windows 也可 Ctrl+Z 回车，Mac 也可 Ctrl+D
```

### 查看当前目录

```bash
pwd               # macOS/Linux — 显示当前路径
cd                # Windows（无参数）— 显示当前路径
```

### 命令行运行 .py 文件

```bash
cd Desktop/python-learning    # 切换到文件所在目录
python hello.py               # 运行（Mac 用 python3 hello.py）
```

### hello.py 代码

```python
# hello.py — 我的第一个 Python 程序
print("Hello, AI Era!")

# 简单计算
total = sum(range(1, 101))
print("1 到 100 的和是:", total)
```

### 故意报错演示（教学用）

```bash
# 在错误目录下运行
cd /                      # 或 cd 到任意不含 hello.py 的目录
python hello.py
# 预期报错：can't open file 'hello.py': [Errno 2] No such file or directory

# 修复
cd Desktop/python-learning # cd 到正确目录
python hello.py            # 运行成功
```

## 录制注意

1. **报错演示要故意且清晰**：2:30 段的"错误目录报错"是本片的关键教学时刻——必须让学生看到完整报错文字，停留 2-3 秒，再演示修复。不要一闪而过。
2. **交互模式的 `>>>` 要放大**：进入交互模式后，给 `>>>` 提示符一个特写，配旁白强调"看到三个大于号就说明 Python 准备好了"。
3. **Windows/Mac 命令差异用字幕条标注**：`pwd` vs `cd`、`python` vs `python3`、`Ctrl+Z` vs `Ctrl+D`——这些差异点用字幕条即时标注，避免混用旁白。
4. **代码仅用已学内容**：hello.py 只用 `print()`、`sum()`、`range()`，不引入函数定义、import 等后续概念，符合课程进度。
5. **提问彩蛋**：提问彩蛋段的 prompt 字幕条需在后期加上，确保观众能暂停照抄。
