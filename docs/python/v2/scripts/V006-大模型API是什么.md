### [0:00-0:30] 开场Hook

【画面】左边：DeepSeek网页版弹出"服务器繁忙，请稍后再试"的截图；右边：VS Code终端里一行命令发出，AI文字回复瞬间刷出来。字幕："网页版频繁繁忙？API给你另一条路"

【旁白】每次用DeepSeek网页版，是不是经常遇到"服务器繁忙，请稍后再试"？但你发现没有，同样的模型，用代码调API的时候却很少碰到这个问题。今天我就带你搞明白——大模型API到底是个什么东西？为什么它能绕过网页限制？又为什么，全班同学一起调上一百次，费用还不到一块钱？

### [0:30-1:45] 核心概念：API调用模型（打电话类比）

【画面】动画演示：一个小人（你的代码）拿起电话→拨号→接通总机（API服务器）→总机转接大模型→对方回答。每一步标注对应的技术术语。最终画面定格在一张对应关系图上。

【旁白】要理解API，我们用大家都熟悉的场景——打电话。你在网页上和DeepSeek聊天，本质上就是你在跟一台远端的大模型服务器对话。那API是什么呢？它就是让你用代码也打这通电话的通道。

整个流程跟打电话一模一样：第一步，你的代码发出一个请求，相当于拿起电话拨号。第二步，这个请求先到达API服务器，相当于总机接到了你的电话。第三步，API服务器把你的消息转发给大模型，相当于总机帮你接通对方。第四步，大模型生成回答，把结果打包成一个JSON返回给你，相当于对方说话，你听到了。

你注意到了吗？网页版是所有人挤在一扇门里，所以经常"服务器繁忙"。而API是一条专用通道，走的是另一条路，所以拥堵的概率小得多。记住这张图，下集写代码的时候，每一步都能对应回来。

### [1:45-3:00] API Key：你的身份证 + 钱包

【画面】左半屏：一张"API Key"的卡片，上面标着`sk-`开头的一串字符，卡片左侧标"身份证"图标，右侧标"钱包"图标。右半屏：终端演示请求时携带api_key的代码片段（灰色淡化处理，不细讲）。

【旁白】那打电话得有电话号码吧？在API的世界里，你的"号码"就是API Key。你会在DeepSeek开放平台上申请到一个，长得像这样，sk-开头，后面跟着一长串字符。

这个Key同时干两件事。第一件，身份认证——服务器看到这把Key，就知道是你来了，相当于你的身份证。没有它，请求直接被拒绝，你连总机都到不了。第二件，计费——服务器根据你这次调用消耗了多少资源，从你账户里扣钱，相当于你的钱包。

所以API Key不是密码，它比密码更重要。你的密码泄露了最多被骚扰，API Key泄露了，别人可以拿你的钱包去消费。这里先记住一个原则：绝对不分享，绝对不上传到GitHub这类公开仓库。我们下节课会专门讲怎么安全地管理它。

### [3:00-4:30] Token：大模型的"字数货币"

【画面】一段中文文字"变量是一个装数据的盒子。"，每个字上方标注token计数：逐字亮起，旁边数字递增。然后切换到英文"The answer is 42."，按单词拆分标注token。字幕："1汉字 ≈ 1-2 token，1英文单词 ≈ 1 token"

【旁白】那API到底怎么计费呢？这就得说一个核心概念——Token。Token是大模型读写文字的计量单位，你可以理解为它的"字数货币"。

大模型不是按"个"或"行"来算的，它把所有文本拆成一小块一小块来处理。对于中文，大概一个汉字消耗一到两个token；对于英文，差不多一个单词一个token。不管是你发给它的输入，还是它回答你的输出，都要算token。

我们来看一个真实的例子。上次V005里我们看到API返回的数据里有一段usage，里面写着prompt_tokens是28，completion_tokens是12，total_tokens是40。这就是说，你发出去的话花了28个token，AI回答的话花了12个token，加一起总共40个token。记住这个数字，一会儿我们要用它算钱。

### [4:30-5:30] 费用低到惊人：算一笔账

【画面】一个简洁的计算器动画：输入"40 token ÷ 1,000,000 × ¥1 = ¥0.00004"。然后放大显示。接着切换成表格：一行"全班50人 × 调用100次 × 每次40 token = 200,000 token"，费用"¥0.2"。字幕："全班调100次 < 1块钱"

【旁白】现在我们来算钱。DeepSeek的deepseek-chat模型，输入大约每百万token一块钱，输出每百万token两块钱。我们就高不就低，统一按两块钱算。

刚才那次调用总共40个token。40除以一百万，再乘以两块钱，等于零点零零零零八元。不到万分之一块钱。

再放大一点：班上50个人，每人调100次，每次40个token，总共才20万token。费用多少？四毛钱。全班折腾半天花不了一块钱。这就是为什么我们敢让全班放开调API，费用真的低到可以忽略。当然前提是你正常使用，别拿它跑死循环。

### [5:30-6:15] 安全原则：Key比密码更重要

【画面】红色警告框弹出，大字："API Key 三不原则"。下方逐条亮起："① 不截图发群 ② 不写进代码传GitHub ③ 不告诉任何人"。然后演示一个`.env`文件的图标，字幕："下集教你安全存放"。

【旁白】既然API Key就是你的钱包，那安全就是头等大事。记住三个"不"：第一，不截图发群里——哪怕只露了一角，别人也能复制走。第二，不写死在代码里然后传到GitHub——这是最常见的翻车方式，一旦公开，爬虫几秒钟就能扫到。第三，不告诉任何人，包括你的同学和室友。

正确做法是把Key放在`.env`文件里，代码运行时再读取。具体怎么做，下集手把手教你。今天记住一句话：Key是你的钱包，保护它就像保护支付宝。

1. 本集纯概念，无代码录屏，画面全部靠动画和图示驱动，视觉节奏要快，避免一张图停留超过15秒。

4. API Key示例字符串用明显的假Key（如`sk-xxxxxxxx1234`），绝不能出现真实Key。
5. 安全原则环节语气加重，这是本课反复强调的红线，语气要有警示感但不能恐吓。
6. 结尾引出V007时要展示运行`python chat.py`的画面，让观众有"下集就能做出这个"的期待感。
7. 提问彩蛋段的 prompt 字幕条需在后期加上，确保观众能暂停照抄。
