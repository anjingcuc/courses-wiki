    01 Windows 基础

    第 01 章 Windows 基础
    硬件 · 系统 · 常用组件

    本章要点

    01计算机组成与操作系统
    台式机与笔记本的硬件构成，硬件与操作系统的关系；用操作系统自带的入口（设备管理器、任务管理器、系统信息）查看硬件信息。结合专业方向理解关键硬件参数（CPU、内存、显卡/显存）。
    02Windows 操作系统历史
    从 Windows 年表看桌面操作系统的发展脉络，市场占有情况与现状；Windows 10 的版本号与版本划分——理解「同是 Windows 10，能力不同」的原因。
    03Windows 10 常见组件
    总体布局、任务栏、任务管理器、文件资源管理器、日常及专业软件。任务管理器是日常排障的第一入口，后续章节将频繁使用。
