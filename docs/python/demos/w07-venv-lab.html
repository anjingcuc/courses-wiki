结果：同一个 numpy 不能同时既是 1.26.4 又是 2.0.2。
怎么办：UV 不会自动装两份，也不会随便选一版。两个项目各用一个独立环境，才能分别安装不同版本。

np.float_：可用 → float64这个旧写法在 1.26.4 里还能用。
np.mean：仍为 2.0一个写法能不能用，不代表整个库能不能用。
两版都能用的写法：np.float64。新作业不依赖这两个历史版本；这里只看同一个旧写法在两版中的差别。
临时环境不会改项目的 pyproject 或全局 site-packages；UV 仍可能写用户级缓存、下载受管 Python / wheel。

Python · 项目的包

          
UV · venv · conda

          
UV 在 pyproject.toml 里记录项目需要哪些包，在 uv.lock 里锁定版本，项目 .venv 里提供 site-packages；venv 常见 pip / requirements 工作流；conda 按所选环境文件与包工作流复现。

          
怎么确认实际用到的模块：sys.executable、sys.path、numpy.__file__

        

      

      

        
别这样理解
PATH 管命令在哪，sys.path 管 import 去哪找；也不要用 PYTHONPATH 手工拼一个“虚拟环境”。

        
观察 / 验证命令（示例）uv tree
uv run --no-sync --locked python -c "import sys; print(sys.executable)"
普通 uv run 可能同步项目环境并写缓存；--no-sync 只用于已建且依赖齐全、锁与声明一致的环境。
