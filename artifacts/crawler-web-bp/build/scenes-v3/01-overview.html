先建立一张总图：Web 演进如何改变爬虫

同一个网址，内容可以在三个地方被造出来——磁盘上、服务器上、浏览器里；还有第四种形态：干脆不造 HTML，直接把数据给你。 这四种是供给形态，不是一条时间轴上的四个年代：④ 与 ③ 同期，只是换了条更省事的通道。

③ 前端渲染库存 1000 → 999 每秒自刷

首屏 HTML 里已经有 1000（<p id="stock">1000</p>），JS 每秒把局部改成 999，用户不用按 F5。要拿「此刻的值」，得抓它背后的 XHR 接口。

F12 → Network → XHR→ 抓接口 / headless
④ 数据接口/data?page=N

④ 不是更晚的世代，而是 ③ 的另一面：AJAX 调的就是这种接口。分页写进 URL，返回纯 JSON——没有 HTML 可解析，也不需要浏览器。

requests.get("/data?page=2").json()→ 零解析
