  <h2 style="font-size:20px;">L4 核心：第一次调用大模型 API</h2>
  <div markdown="1">
  <p>这段代码会在 L4 课堂逐行讲透（openai SDK 兼容写法，DeepSeek / Kimi / GLM 通用）。注意它依赖网络与密钥，
  需要本地运行；这里先读懂结构——<b>base_url 指向哪家服务商、messages 三种角色、response 怎么取文本</b>：</p>

  ```python
  from openai import OpenAI

  client = OpenAI(
      api_key="sk-你的密钥",                      # 千万别写进要提交的代码！
      base_url="https://api.deepseek.com/v1",     # 换服务商只改这里
  )

  resp = client.chat.completions.create(
      model="deepseek-chat",
      messages=[
          {"role": "system", "content": "你是一个耐心的编程助教"},
          {"role": "user",   "content": "用一句话解释什么是变量"},
      ],
  )
  print(resp.choices[0].message.content)
  ```

  <p>没有 API Key？先用下面的运行场模拟「响应处理」环节——把 API 返回的 JSON 结构拆开取值，这是 L6 的预告：</p>
  </div>

  <div class="py-playground" data-py-title="解析一段大模型 API 的返回结构">
    <textarea>import json

# 这是某大模型 API 返回的 JSON（字符串）
response = '''
{
  "id": "chatcmpl-001",
  "model": "deepseek-chat",
  "choices": [
    {
      "role": "assistant",
      "message": {"role": "assistant", "content": "变量是一个名字，绑定了内存里的对象"}
    }
  ],
  "usage": {"prompt_tokens": 12, "completion_tokens": 18}
}
'''

data = json.loads(response)          # JSON 字符串 -> Python 字典
msg = data["choices"][0]["message"]  # 逐层取值
print("模型回答:", msg["content"])
print("消耗token:", data["usage"]["prompt_tokens"] + data["usage"]["completion_tokens"])
</textarea>
