先检查，再清洗：缺失不是 0℃

# df 已由上一页完整定义
print(df.head(3))                 # 先看前几行长什么样
df.info()                         # 列、非空数量、dtype
print(df["temperature"].describe()) # 数值分布
print(df.isna().sum())             # 每列缺失数

df["temperature"] = pd.to_numeric(
    df["temperature"], errors="coerce"
)
clean_df = df.dropna(subset=["temperature"]).copy()
print(clean_df.shape)              # (8, 3)
检查顺序看样品 → 看结构 → 看分布 → 找缺失 head 不代替 info；describe 也不告诉你缺失在哪一行。几种检查互相补充。
本例清洗决策删除 r03，保留“9 → 8”的记录 问题是“比较已观测温度的均值”，r03 没有温度，不能当作 0℃，也不凭空补值。其他问题可能适合 fillna，但必须有业务依据。

运行边界：以上代码在安装了 Pandas 的本地 Python / Notebook 中执行；本课程当前浏览器 Python 运行场尚未加载 Pandas，这不是“Pandas 装不了”。下方 SVG 实验室是明确标注的教学仿真。

筛选、groupby、排序：每次变形都看输出

# clean_df 已由上一页定义
hot_df = clean_df[clean_df["temperature"] >= 30]

city_mean = (
    clean_df.groupby("city")["temperature"]
    .mean()
    .round(1)
    .sort_values(ascending=False)
)
city_mean_df = city_mean.rename("avg_temperature").reset_index()

print(hot_df)        # 4 行：仍是一批观测记录
print(city_mean_df)  # 3 行：每行是一个城市

筛选保留“符合条件的行”；groupby 改变汇总粒度；sort_values 只改变顺序。若对 hot_df 分组，回答的就变成“高温记录均值”，不是本页全量均值。

Matplotlib：用 fig / ax 把汇总表画出来

import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = [
    "Microsoft YaHei", "SimHei", "Noto Sans CJK SC"
]
plt.rcParams["axes.unicode_minus"] = False

# city_mean 已由第 5 页定义：索引是城市，值是均温
fig, ax = plt.subplots(figsize=(7, 4))
ax.bar(city_mean.index, city_mean.values, color="#0284c7")
ax.set_title("各城市平均温度（3 日）")
ax.set_xlabel("城市")
ax.set_ylabel("平均温度（℃）")
ax.set_ylim(0, 35)
ax.bar_label(ax.containers[0], fmt="%.1f")
fig.tight_layout()
fig.savefig("city_mean.png", dpi=150, bbox_inches="tight")
plt.show()
一张图，两个对象fig 是整张画布，ax 是一套坐标系 柱形、标题与轴标落在 ax；整图布局与保存落在 fig。不要再把比较柱形与趋势折线混画在同一标题下。
预期读数广州 32.0 · 北京 29.0 · 上海 27.3℃ 三根柱共享 0–35℃ 的 Y 轴；柱顶标数值，图旁保留汇总表。代码在本地运行后才生成 city_mean.png，仓库不伪造这张输出。

读图与交付：坐标、中文、保存三个陷阱

① 中文标签与负号 
plt.rcParams["font.sans-serif"] = [
    "Microsoft YaHei", "SimHei", "Noto Sans CJK SC"
]
plt.rcParams["axes.unicode_minus"] = False
候选字体也要机器上实际安装；若仍报缺字形，先查可用字体，而不是删中文标题。
② savefig ≠ show fig.savefig(...) 写图片文件；plt.show() 显示图形窗口。脚本中通常先保存再 show，避免部分后端在 show 后清空当前图。Notebook 自动显示也不等于已经保存。
③ 交付可读 dpi=150 控制位图分辨率，bbox_inches="tight" 收紧空白；标题、单位、数据表与一句结论一起交付。
